# 英文與日文的國際能力分級

查核日期：2026-11-24

描述英文學習程度時，常用歐洲共同語文參考架構（CEFR）的 A1 到 C2。描述日文檢定資格時，常用日本語能力試驗（JLPT）的 N5 到 N1。兩者回答的問題不同：CEFR 描述一個人能用語言完成哪些事，JLPT 則說明考生通過哪一級日文考試。CEFR 也適用於日文。[歐洲理事會的能力框架](https://www.coe.int/en/web/common-european-framework-reference-languages/introduction-and-context)｜[JLPT 官方對照](https://www.jlpt.jp/e/about/cefr_reference.html)

## 英文的六個常用等級

| CEFR | 在這個程度能做什麼 |
| --- | --- |
| A1 入門 | 能自我介紹。對方放慢速度並協助時，能回答簡單的個人問題。 |
| A2 基礎 | 能在購物、問路等熟悉情境中，交換簡單而具體的資訊。 |
| B1 中階 | 能掌握熟悉話題的重點、處理多數旅行情境，並簡述經驗與理由。 |
| B2 中高階 | 能理解較複雜內容的主旨，參與自己領域的技術討論，並說明不同選項的利弊。 |
| C1 進階 | 能理解長文中的弦外之音，在學術或專業場合靈活表達複雜想法。 |
| C2 精熟 | 能整合多個口頭及書面來源，即使討論複雜問題，也能精確表達細微差異。 |

各級以可觀察的語言行為描述。若聽說讀寫程度有落差，可分項記錄，例如「閱讀 B2、口語互動 B1」。[歐洲理事會六級總表](https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-%20cefr-3.3-common-reference-levels-global-scale)

### 英文檢定怎麼報分

| 考試 | 分數與用途 |
| --- | --- |
| IELTS 雅思 | 常見於留學與移民申請。聽說讀寫各有分數，另報整體級分，最高 9，可見 6.5 等半級分。[IELTS 官方說明](https://ielts.org/ielts-usa) |
| TOEFL iBT 托福 | 常見於大學入學申請。2026 年 1 月 21 日起，四科與總成績採 1–6 級，每半級一格。兩年過渡期另列可比較的 0–120 總分。新制總成績 4 或 4.5 對應 B2。[ETS 新制與對照表](https://www.ets.org/toefl/institutions/ibt/score-scale-update.html) |
| TOEIC L&R 多益聽讀 | 常見於職場英文評量。聽力與閱讀各 5–495 分，合計 10–990 分。口說與寫作另有測驗。[IIBC 聽讀成績說明](https://www.iibc-global.org/english/toeic/test/lr/guide05.html) |

## 日文 JLPT 五級與 CEFR 的關係

自 2025 年 12 月場次起，JLPT 在合格者的成績單上依總分標示 CEFR 參考級別。下表由易到難，各級滿分皆為 180，考生還須達到各計分區的及格門檻。[JLPT 成績單與官方對照](https://www.jlpt.jp/e/about/cefr_reference.html)

| JLPT | 合格者總分與 CEFR 參考級別 |
| --- | --- |
| N5（最初階） | 80–180 分為 A1 |
| N4 | 90–180 分為 A2 |
| N3 | 95–103 分為 A2，104–180 分為 B1 |
| N2 | 90–111 分為 B1，112–180 分為 B2 |
| N1（最高階） | 100–141 分為 B2，142–180 分為 C1 |

例如，同樣通過 N2，總分 110 與 115 的考生，成績單分別標示 B1 與 B2。這只涵蓋語言知識、閱讀與聽力；若要判斷一個人能否主持日文會議或寫商務信，仍需要口語互動或寫作表現作為依據。[JLPT 對能力範圍的說明](https://www.jlpt.jp/e/about/cefr_reference.html)

## 「全球最流行」能從數據看出什麼

IELTS 主辦方公布，2023 年全球施測超過 400 萬次。JLPT 的 2025 年 12 月單次考期有 1,036,380 人報名、876,484 人到考，當次到考人數最多的是 N3（249,389 人）。這些數字顯示兩項考試都有大規模使用。年份、統計期間與測驗目的各異，無法據此排出全球所有語言檢定的第一名。CEFR 是可供多種考試採用的框架，本身沒有單一報考人數。[IELTS 年度公告](https://ielts.org/news-and-insights/ielts-trusted-by-millions-in-2023)｜[JLPT 該場全球統計](https://www.jlpt.jp/e/statistics/archive/202502.html)
## 專案教材的口說與聽力難度

評估日期：2026-11-24。英文衝刺教材的核心任務約 A2–B1，日文衝刺教材的基礎進度約 A1–A2，後段在熟悉的生活與工作情境延伸到 B1。以下按聽力理解、口語表達與互動的任務要求估計。級別描述的是教材難度；個人程度還要看換說話者、換題目後的無稿表現。[歐洲理事會 CEFR 分項自評表](https://www.coe.int/en/web/common-european-framework-reference-languages/table-2-cefr-3.3-common-reference-levels-self-assessment-grid)

| 教材 | 口說 | 聽力 |
| --- | --- | --- |
| 英文口說與聽力衝刺 | 提示下用三句話自介約 A1–A2。脫稿說一分鐘專案經驗、交代行動與理由、接續追問約 B1。能即席比較替代方案並回應反駁時，該題才接近 B2。 | 聽出訂單、時間與更動約 A2。換人以清楚自然語速提問，仍能聽懂新的技術限制或優先順序，約 B1。 |
| 日文口說與聽力衝刺 | 自介、請對方重說、確認金額約 A1–A2。無稿說明進度、處理對方臨時改條件，或在追問後補充理由，約 B1。 | 慢速辨認熟悉詞句約 A1，從短對話抓出金額、時間或目的地約 A2。首次聽到改述後，能掌握時程變動及其影響，約 B1。 |
| Context Lab 英日文情境題庫 | 兩語各有 89 個情境。依樣本，套句完成簡短交易約 A2；換對象後用自己的話說明貢獻、處理異議或補舉例子，約 B1，部分延伸討論接近 B2。 | 兩語樣本主要是短場景。擷取明確資訊約 A2，聽懂一段工作敘述的因果與重點約 B1。語速、重播與字幕都會影響實際難度。 |
| 英文 keynote、日文產品簡報專用教材 | 英文用短句排演 30 分鐘講稿，日文從 30 秒介紹進展到 5 分鐘提示卡簡報。照稿演練本身難以定級；若能脫稿說明熟悉產品並應對隨機追問，兩套的專題口說目標約 B1–B2。 | 熟悉措辭的短問句約 A2–B1。換問法後仍能掌握問題約 B1；若需持續跟上專業質疑及論據，該段可接近 B2。 |

判讀時最有區別的是**換條件後能做什麼**。例如同樣練會議改期，只要辨認新時間，大致是 A2 聽力；聽懂改期原因，再向同事解釋對交付的影響，才同時用到接近 B1 的聽力與口說。日文可沿用這套分項描述，JLPT 的 CEFR 參考級別僅涵蓋語言知識與接收能力，據此無法替口說指定 N 級。[JLPT 官方對照範圍](https://www.jlpt.jp/e/about/cefr_reference.html)
