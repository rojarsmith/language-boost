# 敬語、稱謂、相槌與商務語域

這章提供「不會太隨便，也不會敬語堆到說不出口」的安全基線。日本公司、海外子公司、通路商與個人偏好都可能不同；名片、會議邀請與本人自我介紹，永遠比你猜測的規則可靠。

讀法中的 `/` 是短停頓，`//` 是句尾。先求清楚、準確、尊重，再追求華麗敬語。

## 初學者的安全語域

正式商務場合預設使用 `です／ます`。只需熟練三層，不必一開始創造複雜敬語。

| 層次 | 用途 | 自然日文 | 假名讀法 |
|---|---|---|---|
| 基本敬體 | 一般說明 | こちらが本日の資料です。 | こちら が / ほんじつ の しりょう です。// |
| 安全請求 | 請對方動作 | こちらをご確認いただけますか。 | こちら を / ごかくにん いただけます か。// |
| 謙讓表達 | 自己動作 | 私からご説明いたします。 | わたし から / ごせつめい いたします。// |

不要把所有動詞都改成敬語。句子太長而說錯，通常比簡潔的 `です／ます` 更影響專業感。

### 過度隨便與安全版

| 避免 | 安全版 | 假名讀法 | 原因 |
|---|---|---|---|
| ちょっと待って。 | 少々お待ちください。 | しょうしょう / おまち ください。// | 前者對高階主管太隨便。 |
| 分からないです。 | 現時点では分かりませんので、確認いたします。 | げんじてん では わかりません ので、/ かくにん いたします。// | 加入下一步。 |
| 無理です。 | 現時点では対応が難しい状況です。 | げんじてん では / たいおう が むずかしい じょうきょう です。// | 說明目前範圍，不粗暴拒絕。 |
| いいですよ。 | その内容で進めて問題ありません。 | その ないよう で すすめて / もんだい ありません。// | 正式同意要清楚。 |

## 姓名與職稱

### 最安全的選擇順序

1. 先看會議邀請、名片與本人署名的正式職稱。
2. 對方有日文職稱時，可用 `姓＋職稱`，例如 `田中社長`、`佐藤部長`。
3. 不確定職稱時，用 `姓＋様`；較熟悉且對方允許時才用 `姓＋さん`。
4. 非日本姓名先確認姓與名、希望的發音及稱呼。
5. 不用 `社長様`、`部長様` 作預設，因職稱本身已含敬意。

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 確認讀音 | **[スミス]** 様とお呼びしてよろしいでしょうか。 | **[スミス]** さま と および して / よろしい でしょう か。// |
| 確認職稱 | 現在のお役職を、もう一度確認させていただけますか。 | げんざい の おやくしょく を、/ もう いちど かくにん させて いただけます か。// |
| 對社長 | 田中社長、ご質問ありがとうございます。 | たなか しゃちょう、/ ごしつもん ありがとうございます。// |
| 不確定 | 鈴木様、この理解でよろしいでしょうか。 | すずき さま、/ この りかい で よろしい でしょう か。// |

`Vice President` 可能對應 `副社長`、`執行役員`、`本部長` 或英文 VP，不能自行翻譯。使用對方名片上的原職稱。

## 說自己人與對方公司的人

對外說話時，自己的公司用 `弊社`，對方公司在口語可用 `御社`。提到自己公司的同事時，通常不加 `さん`；直接說公司、姓氏與職責。若對方是集團內另一家法人，是否視為內部要看雙方文化，第一次仍以正式稱呼為安全。

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 我方公司 | 弊社で確認し、明日までに回答いたします。 | へいしゃ で かくにん し、/ あした まで に かいとう いたします。// |
| 對方公司 | 御社では、どの市場を優先されていますか。 | おんしゃ では、/ どの しじょう を ゆうせん されて います か。// |
| 引介我方同事 | 弊社の佐藤が、技術面をご説明いたします。 | へいしゃ の さとう が、/ ぎじゅつめん を ごせつめい いたします。// |
| 請同事補充 | 技術の詳細は、佐藤から補足いたします。 | ぎじゅつ の しょうさい は、/ さとう から ほそく いたします。// |

書面中的對方公司通常寫 `貴社`，讀音是 `きしゃ`；口語不要說 `貴社`，以免和 `記者` 同音造成混淆。

## 初學者只需熟練的敬語動詞

| 一般意思 | 安全商務形式 | 例句 | 假名讀法 |
|---|---|---|---|
| 說 | 申し上げる | 結論から申し上げます。 | けつろん から / もうしあげます。// |
| 問／拜訪 | 伺う | 一点、伺ってもよろしいでしょうか。 | いってん、/ うかがっても よろしい でしょう か。// |
| 看 | 拝見する | 資料を拝見しました。 | しりょう を / はいけん しました。// |
| 做 | いたす | 私から説明いたします。 | わたし から / せつめい いたします。// |
| 收到／請對方做 | いただく | ご確認いただけますか。 | ごかくにん / いただけます か。// |
| 知道／接受 | 承知する | 日程について承知しました。 | にってい に ついて / しょうち しました。// |

`承知しました` 可被理解為你接受或承諾執行，只有在確實有權同意時才使用。

## 相槌不等於同意

日文對話需要相槌，但重大條件後若只回 `はい`，對方可能以為你同意。

| 相槌 | 假名讀法 | 通常功能 | 是否表示正式同意 |
|---|---|---|---|
| はい。 | はい。// | 有聽到、請繼續 | 不一定；有誤解風險 |
| ええ。 | ええ。// | 較柔和的接話 | 不適合拿來確認正式條件 |
| そうなんですね。 | そう なん です ね。// | 原來如此 | 否 |
| おっしゃる点は理解しました。 | おっしゃる てん は / りかい しました。// | 理解對方觀點 | 否 |
| 承知しました。 | しょうち しました。// | 已知悉並接受處理 | 常會被理解為是 |
| その条件で合意します。 | その じょうけん で / ごうい します。// | 明確同意 | 是；須有權限 |

### 只表示理解

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| ご説明の内容は理解しました。 | ごせつめい の ないよう は / りかい しました。// | 我理解說明內容。 |
| ご要望は理解しましたが、対応の可否は社内確認が必要です。 | ごようぼう は りかい しました が、/ たいおう の かひ は / しゃない かくにん が ひつよう です。// | 理解需求，但能否對應需內部確認。 |
| 今の「はい」は、理解したという意味で、同意ではありません。 | いま の はい は、/ りかい した と いう いみ で、/ ごうい では ありません。// | 剛才的「是」是理解，不是同意。 |

### 明確同意前先確認權限

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| 私の権限で合意できる内容か、確認させてください。 | わたし の けんげん で / ごうい できる ないよう か、/ かくにん させて ください。// | 請讓我確認這是否在我的同意權限內。 |
| この条件は `[CONFIRM]` です。責任者の承認後に、正式に回答します。 | この じょうけん は / **かくにん が ひつよう** です。/ せきにんしゃ の しょうにんご に、/ せいしき に かいとう します。// | 這條件需要確認，主管核准後正式答覆。 |

`[CONFIRM]` 是教材標籤，正式對話時念 `確認が必要です`，不要念英文。

## 禮貌打斷與輪流發言

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 插一句確認 | お話の途中で失礼します。一点だけ確認してもよろしいでしょうか。 | おはなし の とちゅう で / しつれい します。/ いってん だけ かくにん しても / よろしい でしょう か。// |
| 沒說完 | 申し訳ありません。あと一点だけ説明させてください。 | もうしわけ ありません。/ あと いってん だけ / せつめい させて ください。// |
| 請對方先說 | 失礼しました。どうぞお続けください。 | しつれい しました。/ どうぞ おつづけ ください。// |
| 交還發言權 | 私からは以上です。ご意見を伺ってもよろしいでしょうか。 | わたし から は いじょう です。/ ごいけん を うかがっても よろしい でしょう か。// |
| 沉默確認 | 少しお考えになる時間が必要でしょうか。 | すこし おかんがえ に なる じかん が / ひつよう でしょう か。// |

不要害怕兩三秒沉默。說完後停下來，比用 `えーと` 填滿空間更容易讓人理解。

## 同意、不同意與保留

### 同意觀點但不承諾條件

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| その考え方には賛成です。具体的な条件は別途確認させてください。 | その かんがえかた に は / さんせい です。/ ぐたいてき な じょうけん は / べっと かくにん させて ください。// | 我同意這個思路，具體條件另行確認。 |
| 方向性は理解していますが、まだ正式決定ではありません。 | ほうこうせい は りかい して います が、/ まだ せいしき けってい では ありません。// | 理解方向，但尚未正式決定。 |

### 禮貌不同意

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| お考えは理解できます。一方で、現時点では別のリスクもあると考えています。 | おかんがえ は りかい できます。/ いっぽう で、/ げんじてん では べつ の リスク も ある と / かんがえて います。// | 理解您的想法，但目前也有另一風險。 |
| その前提については、もう一度確認が必要だと思います。 | その ぜんてい に ついて は、/ もう いちど かくにん が ひつよう だ と / おもいます。// | 該前提需要再確認。 |
| 現在の情報だけでは、その結論には至っていません。 | げんざい の じょうほう だけ では、/ その けつろん に は / いたって いません。// | 依目前資訊尚無法得到該結論。 |

不要用含糊的笑容取代不同意。若決策重要，會後紀錄要明寫「理解」「待確認」或「已同意」。

## 道歉、訂正與不知道

日文商務中的道歉不必變成自我貶低。承認事實、立即訂正、說明影響與下一步。

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 不知道 | 現時点では正確にお答えできません。確認して、**[日付]** までに回答いたします。 | げんじてん では / せいかく に おこたえ できません。/ かくにん して、/ **[ひづけ]** まで に かいとう いたします。// |
| 當場訂正 | 先ほどの説明を訂正させてください。正しくは **[正確內容]** です。 | さきほど の せつめい を / ていせい させて ください。/ ただしく は / **[せいかく な ないよう]** です。// |
| 誤導致歉 | 誤解を招く説明となり、申し訳ございません。 | ごかい を まねく せつめい と なり、/ もうしわけ ございません。// |
| 說明影響 | この訂正は、次のステップには影響しません。 | この ていせい は、/ つぎ の ステップ に は / えいきょう しません。// |
| 需要改計畫 | この訂正により、評価条件を見直す必要があります。 | この ていせい に より、/ ひょうか じょうけん を みなおす / ひつよう が あります。// |

## 名片、鞠躬與非語言行為

- 名片雙手遞接，文字朝向對方；收到後先確認姓名與職稱，不立刻塞進口袋或在名片上寫字。
- 多人交換名片時，依現場主人安排；不確定順序就稍候觀察。
- 一般問候輕鞠躬即可，不必追求固定角度；線上會議則以清楚點頭代替。
- 眼神接觸保持自然，不必持續盯視；跨文化團隊中以對方舒適度為準。
- 不碰觸對方、不評論外貌；是否握手由對方或現場文化帶領。

名片確認句：

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| お名刺を頂戴いたします。ありがとうございます。 | おめいし を / ちょうだい いたします。/ ありがとうございます。// | 謝謝您給我名片。 |
| お名前は **[高橋]** 様で、読み方は「たかはし」でよろしいでしょうか。 | おなまえ は **[たかはし]** さま で、/ よみかた は「たかはし」で / よろしい でしょう か。// | 姓名是高橋，讀作「たかはし」，對嗎？ |

## 容易踩線的主題

不主動評論政治、宗教、歷史爭議、收入、婚姻生育、疾病、外貌、公司八卦、客戶機密或國族刻板印象。對方主動說時，可以聽，但不必表態或追問。

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 不熟悉 | その点については詳しくないため、軽々しく意見を申し上げないようにしています。 | その てん に ついて は / くわしく ない ため、/ かるがるしく いけん を もうしあげない よう に / して います。// |
| 不談私人細節 | 個人的なことですので、詳しい話は控えさせてください。 | こじんてき な こと です ので、/ くわしい はなし は / ひかえさせて ください。// |
| 保護機密 | その内容は、公開情報の範囲でのみお答えします。 | その ないよう は、/ こうかい じょうほう の はんい で のみ / おこたえ します。// |
| 轉回安全話題 | もしよろしければ、最近の市場動向について伺えますか。 | もし よろしければ、/ さいきん の しじょう どうこう に ついて / うかがえます か。// |

## 最小敬語卡

只背下面八句，就能處理多數高階會議。

| 功能 | 自然日文 | 假名讀法 |
|---|---|---|
| 自介 | EDT の **[姓名]** と申します。 | イー・ディー・ティー の / **[せいめい]** と もうします。// |
| 請教 | 一点、伺ってもよろしいでしょうか。 | いってん、/ うかがっても よろしい でしょう か。// |
| 請確認 | こちらをご確認いただけますか。 | こちら を / ごかくにん いただけます か。// |
| 理解 | おっしゃる点は理解しました。 | おっしゃる てん は / りかい しました。// |
| 未同意 | ただし、合意については社内確認が必要です。 | ただし、/ ごうい に ついて は / しゃない かくにん が ひつよう です。// |
| 不知道 | 正確な情報を確認してから回答いたします。 | せいかく な じょうほう を かくにん して から / かいとう いたします。// |
| 打斷 | お話の途中で失礼します。 | おはなし の とちゅう で / しつれい します。// |
| 致謝 | 貴重なご意見をいただき、ありがとうございます。 | きちょう な ごいけん を いただき、/ ありがとうございます。// |

## 自我檢查

正式場合前逐項確認：

- 我知道對方姓名的正確讀音與正式職稱。
- 我能分辨 `はい`、`理解しました`、`承知しました`、`合意します` 的承諾強度。
- 我提到自己同事時不亂加敬稱，提到對方時不直呼其名。
- 我不知道時會說確認人與日期，不只說 `分かりません`。
- 我能禮貌不同意，也能在誤說後立即訂正。
- 我沒有把文化習慣當作每個日本人都相同的絕對規則。
