# 商務會議開場、轉場、收尾與追蹤

這章建立一條固定路線：**問候 → 自介 → 議程 → 產品定位 → 討論 → owner/action/date → 致謝**。先背短版，再替換姓名、職稱、日期與主題。讀法中的 `/` 是短停頓，`//` 是句尾。

稱謂與內外有別的規則見 [敬語、稱謂與語域](26_ETIQUETTE_AND_REGISTER.md)。

## 聽不懂與確認問題

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 重說 | 恐れ入りますが、もう一度、少しゆっくりお願いできますか。 | おそれいります が、/ もう いちど、/ すこし ゆっくり おねがい できます か。// |
| 漏一詞 | 大意は理解できましたが、最後の用語だけ、もう一度お願いできますか。 | たいい は りかい できました が、/ さいご の ようご だけ、/ もう いちど おねがい できます か。// |
| 確認 | ご質問は、**[主題]** について、という理解でよろしいでしょうか。 | ごしつもん は、/ **[しゅだい]** に ついて、/ と いう りかい で よろしい でしょう か。// |
| 二選一 | 技術面についてでしょうか。それとも商務面についてでしょうか。 | ぎじゅつめん に ついて でしょう か。/ それとも しょうむめん に ついて でしょう か。// |
| 思考時間 | 重要なご質問です。二つに分けてお答えします。 | じゅうよう な ごしつもん です。/ ふたつ に わけて おこたえ します。// |

`はい` 有時只是「我在聽」，不是同意；需要留下正式結論時，必須再用完整句確認。

## 回答、交棒與 `[CONFIRM]`

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 先結論 | 結論から申し上げますと、現時点では **[回答]** です。 | けつろん から もうしあげます と、/ げんじてん では / **[かいとう]** です。// |
| 分範圍 | 確認済みの範囲と、追加確認が必要な範囲を分けてご説明します。 | かくにんずみ の はんい と、/ ついか かくにん が ひつよう な はんい を わけて / ごせつめい します。// |
| 交棒 | 製品全体については私がお答えし、技術の詳細は **[姓]** から補足いたします。 | せいひん ぜんたい に ついて は / わたし が おこたえ し、/ ぎじゅつ の しょうさい は / **[せい]** から ほそく いたします。// |
| 未核准 | 価格と契約条件は `[CONFIRM]` です。社内で確認し、**[日付]** までに文書で回答いたします。 | かかく と けいやく じょうけん は / **かくにん が ひつよう** です。/ しゃない で かくにん し、/ **[ひづけ]** まで に ぶんしょ で かいとう いたします。// |
| 防誤解 | 現時点では、決定ではなく検討事項です。 | げんじてん では、/ けってい では なく / けんとう じこう です。// |

`[CONFIRM]` 是教材標籤，不要在正式對話中照念；請說 `確認が必要です` 或使用上表完整句。

## 會後 Email 範本

書面不必背，但應在 24 小時內寄出。每個 `[CONFIRM]` 都要有負責人與期限。

### 一般版

> 件名：EDT HMI Studio お打ち合わせのお礼と次のステップ  
>  
> **[会社名]**  
> **[姓] [役職／様]**  
>  
> 本日はお時間をいただき、誠にありがとうございました。  
> EDT HMI Studio と **[用途／市場]** について、貴重なご意見をいただき、感謝申し上げます。  
>  
> 本日の確認事項は、以下のとおりです。  
> 1. **[負責人]**：**[動作]** — **[日付]** まで  
> 2. **[負責人]**：**[動作]** — **[日付]** まで  
> 3. 当社：**[CONFIRM 項目]** を確認し、**[日付]** までに回答  
>  
> 認識に相違がございましたら、お知らせください。  
> 引き続き、どうぞよろしくお願いいたします。  
> **[姓名]**

口頭練習用讀法：

> ほんじつ は おじかん を いただき、/ まこと に ありがとうございました。//  
> ほんじつ の かくにん じこう は、/ いか の とおり です。//  
> にんしき に そうい が ございましたら、/ おしらせ ください。//  
> ひきつづき、/ どうぞ よろしく おねがい いたします。//

### 說錯後修正

> 件名：本日のお打ち合わせ内容の訂正  
>  
> 本日、私から **[錯誤說法]** とご説明しましたが、正しくは **[核准答案]** です。  
> また、適用範囲は **[限制]** です。  
> 誤解を招く説明となり、申し訳ございません。  
> 今後の進め方への影響は **[有／無與原因]** です。

口頭練習用讀法：

> ほんじつ、/ わたし から **[あやまった せつめい]** と ごせつめい しました が、/ ただしく は **[かくにんずみ の こたえ]** です。//  
> ごかい を まねく せつめい と なり、/ もうしわけ ございません。//

## 過關標準

- 不看稿完成七句流程。
- 聽不懂時先確認，不用 `はい` 假裝理解。
- 所有 `[CONFIRM]` 都能說出確認對象與回覆日期。
- 收尾完整說出 owner、action、date。
- 會後摘要與口頭共識一致，沒有新增承諾。
