# EDT HMI Studio 現場 Demo 腳本

目標：用 10 到 12 分鐘證明「同一專案串起 Design、Logic、Protocol、產生 C 與實機前驗證」，而不是追求功能大雜燴。主路徑只使用 a7cc2a8 追蹤版的 EVK Coffee Bar；日本客戶用的 Shizuku 洗衣機路徑另見 `07B_SHIZUKU_WASHER_DEMO_SCRIPT.md`。

## 1. Demo 契約

| 項目 | 固定內容 |
|---|---|

| 主範例 | examples/evk043027b-coffee-bar.json |

## 2. 已核對的事實卡

上台前把本表印成一張提示卡。只要臨場緊張，就回到「5、3、23、1、1」。

|---|---:|

| Stored widget nodes，含巢狀 children | 106 |
| 展開 reusable container instances 後的 generated/rendered widgets | 200 |
| Reusable container definitions | 3 |
| Languages | 3：en、zh-TW、ja |
| Tags | 23 |
| Modbus RTU links | 1 |
| Devices | 1 |
| Logic graphs | 1 |
| Animations | 22 |
| Text resources | 41 |
| Typographies | 16 |
| Image payloads | 0 |
| Font payloads | 0 |
| Video／media payloads | 0 |

對外只講最容易理解的三個數字：

「このサンプルには、五つの画面、三つの言語、二十三のタグがあります。」

かな：

「この サンプル には、いつつ の がめん、みっつ の げんご、にじゅうさん の タグ が あります。」

不要對外說「有 200 個畫面元件」而不解釋計算方式。51 是 top-level placements，106 是 JSON 中含 child 的儲存 nodes，200 是 reusable container instance 展開後的產生／渲染數；三者都正確但意義不同。

## 3. 上台前 24 小時檢查

- 確認來源 HEAD 或指定展示 ref 仍為 a7cc2a8；若已變更，重新核對範例與數字。
- 主線使用追蹤檔 examples/evk043027b-coffee-bar.json；若改走 Shizuku，必須完整切換到 07B 的動作、數字與限制，不混用兩個 Demo。
- 開啟專案後逐一確認 Home、Drinks、Pay、Brewing、Settings。
- 確認語言循環 en → zh-TW → ja 與實際顯示順序；若順序不同，以當天實測為準。
- 確認 NavRail、DrinkCard、StatRow 三個 reusable container definitions 可被指出。
- 確認 pay countdown logic graph 可開啟。
- 確認 protocol 區可看到 1 個 Modbus RTU link、1 個 device、23 個 tags。
- 確認 Code Preview 能看到 ui、events、logic 的生成檔。
- 若要跑 Emulator，先確認 Emscripten 與 LVGL 設定；重新啟動後完整走一次。
- 準備 60 到 90 秒的備用錄影或截圖，畫面至少涵蓋 navigation、語言切換、logic、tag 與 Code Preview。
- 關閉通知、通訊軟體與自動更新；電源接妥；把螢幕縮放與瀏覽器縮放固定。
- Live AI 不登入、不輸入 key、不放進主線。
- 無已預演的實際 EVK、正確 probe 與 STM32CubeCLT，就不按 Flash。

## 5. 預覽模式的現場選擇

| 當天條件 | 使用模式 | 必須說明 |
|---|---|---|
| Emulator 已完整預演 | 走黃金路徑 | 產生 C＋真實 LVGL；仍不等於實機 |
| Emscripten／LVGL 設定不穩 | Prototype 加 Code Preview，再播放備用錄影 | Prototype 是 Canvas2D imitation，不是假裝 Emulator |
| 只剩預建 Simulator | 可展示 LVGL 渲染 | 它不執行本次完整 event、logic 與新產生 C |
| 實機與工具鏈已完整預演 | Emulator 後可加 Build／Flash | 明講板卡、韌體、probe 與測試條件 |

## 6. H747 與 F746 替代 Demo

主 Demo 不臨時更換。只有客戶需求與設備條件明確時，才在會前選替代範例。

### A. H747 Coffee Machine

追蹤檔：examples/h747-coffee-machine.json

已核對：

- 4 screens。
- 46 top-level placements。
- 162 stored／expanded widgets。
- en、zh-TW、ja 三種語言。
- 13 tags、28 animations、55 texts。
- 1 組 Modbus RTU 設定。
- 0 media payloads。
- 沒有 logic graph。

適合：展示 800×480 H747 UI、較完整的視覺設計、方向支援或 H747 實機路徑。

不適合拿來證明：

- 這個範例沒有 media payload，所以不能因 H747 profile 支援特定影片路徑，就說本範例已展示 Video。
- 沒有 logic graph，不要用它作節點邏輯主秀。
- CAN 仍只有 loopback 層級，不是 widget/tag 通訊 Demo。

日文 caveat：

「H747には限定的な動画再生経路がありますが、このサンプルには動画データが含まれていません。」

かな：

「エイチ なな よん なな には げんていてき な どうが さいせい けいろ が あります が、この サンプル には どうが データ が ふくまれて いません。」

### B. H747 Serial Commands Responder

追蹤檔：examples/h747-serial-commands-responder.json

已核對：

- 1 screen、14 widgets、1 language。
- 4 tags、1 logic graph。
- UART command、panel-answers。

適合：回答 controller／host 主動送命令、panel 回應的技術問題。

不適合：不是完整產品視覺展示，也不能延伸成 CAN 或所有 serial protocol 都已驗證。

### C. F746 Modbus HMI

追蹤檔：examples/f746-modbus-hmi.json

已核對：

- 舊版 pages 資料結構，由 migration 路徑支援。
- 1 個 Main page、3 widgets、3 tags。
- Modbus RTU。
- 無 logic graph、無 animations。

適合：最小化展示 F746 與 Modbus binding，或證明舊專案資料可經 migration 讀取。

不適合：高階主管的主視覺 Demo、Video、複雜 logic、多語或大型專案規模。

日文 caveat：

「F746のサンプルは、Modbusバインディングを確認するための最小構成です。製品全体の表現力を示すサンプルではありません。」

かな：

「エフ なな よん ろく の サンプル は、モドバス バインディング を かくにん する ため の さいしょう こうせい です。せいひん ぜんたい の ひょうげんりょく を しめす サンプル では ありません。」

## 8. 故障時的 30 秒復原

### Emulator 啟動失敗

立刻說：

「デモ環境の都合で、ここでは事前に確認した結果をご説明します。」

かな：

「デモ かんきょう の つごう で、ここ では じぜん に かくにん した けっか を ごせつめい します。」

接著播放備用錄影或展示 Code Preview。不要在客戶面前重裝 toolchain。

### 值沒有更新

「通信条件を確認する必要があるため、ここでは設定とバインディングをご説明します。」

かな：

「つうしん じょうけん を かくにん する ひつよう が ある ため、ここ では せってい と バインディング を ごせつめい します。」

回到 link、device、tag、binding 四層畫面，說清資料模型，不猜連線原因。

### Build 或 Flash 失敗

「安全のため、この場では書き込みを繰り返しません。ログと実機条件を確認して、結果をお送りします。」

かな：

「あんぜん の ため、この ば では かきこみ を くりかえしません。ログ と じっき じょうけん を かくにん して、けっか を おおくり します。」

### 被問到不知道的規格

「対象のボード、接続方式、必要な性能条件を確認してから、正確に回答します。」

かな：

「たいしょう の ボード、せつぞく ほうしき、ひつよう な せいのう じょうけん を かくにん して から、せいかく に かいとう します。」
