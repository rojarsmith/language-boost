# 商務餐敘角色扮演

本章把 [商務餐敘與日常交流](24_DINING_SMALL_TALK.md) 變成壓力演練。每個情境依序練 Level 1、2、3；一次只讓對方說一句，等你回答後才繼續。

## 三級難度

1. **Level 1 — 固定題：** 看著表格回答。
2. **Level 2 — 自然追問：** 對方改寫問題，你必須追問一次。
3. **Level 3 — 社交壓力：** 對方勸酒、誤解你的 `はい`、問敏感資訊或要求當場承諾。

所有價格、折扣、毛利、獨家權、付款政策、合約與招待權限都標為 `[CONFIRM]`。氣氛愉快不會擴大你的授權。

## Scenario 1 — 到場、稱謂與座位

### 情境

你最後一個到包廂。子公司總經理與通路商副總都在場，座位尚未指示。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | 王さん、こちらへどうぞ。 | おう さん、/ こちら へ どうぞ。// |
| 2 | 今日は初めての方もいらっしゃいますので、自己紹介をお願いします。 | きょう は はじめて の かた も / いらっしゃいます ので、/ じこしょうかい を おねがい します。// |
| 3 | お好きな席にお座りください。 | おすき な せき に / おすわり ください。// |

### 必須回應

| 功能 | 自然日文 | 假名讀法 |
|---|---|---|
| 問座位 | ありがとうございます。どちらに座ればよろしいでしょうか。 | ありがとうございます。/ どちら に すわれば / よろしい でしょう か。// |
| 自介 | EDT の王と申します。海外事業を担当しております。本日はよろしくお願いいたします。 | イー・ディー・ティー の おう と もうします。/ かいがい じぎょう を たんとう して おります。/ ほんじつ は よろしく おねがい いたします。// |

### 過關

- 沒有自行搶位。
- 第一次就正確稱呼對方；不確定時使用 `姓＋様`。
- 自我介紹在 20 秒內。

## Scenario 2 — 乾杯與反覆勸酒

### 情境

業務副總熱情勸酒。你因體質不能喝，但希望一起乾杯。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | まずはビールで乾杯しましょう。 | まず は ビール で / かんぱい しましょう。// |
| 2 | 一杯だけなら大丈夫でしょう。 | いっぱい だけ なら / だいじょうぶ でしょう。// |
| 3 | 私の杯を受けられないのですか。 | わたし の さかずき を / うけられない の です か。// |

### 必須回應

| 強度 | 自然日文 | 假名讀法 |
|---|---|---|
| 第一次 | ありがとうございます。ただ、体質的にお酒が飲めませんので、ノンアルコールで乾杯させてください。 | ありがとうございます。/ ただ、/ たいしつてき に おさけ が のめません ので、/ ノンアルコール で かんぱい させて ください。// |
| 再被勸 | お気持ちは本当にうれしいのですが、飲むことができません。ウーロン茶で乾杯させてください。 | おきもちは ほんとう に うれしい の です が、/ のむ こと が できません。/ ウーロンちゃ で かんぱい させて ください。// |

### 過關

- 先致謝，但拒絕清楚、不留「可能再喝」的空間。
- 立刻提出無酒精替代品。
- 不編造吃藥、開車等短期理由，除非真實。

## Scenario 3 — 過敏資訊沒有傳到餐廳

### 情境

第一道菜含蝦，而你有嚴重甲殼類過敏。主人說「少量應該沒關係」。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | こちらは海老を使った料理です。 | こちら は / えび を つかった りょうり です。// |
| 2 | 少しだけなら大丈夫ですか。 | すこし だけ なら / だいじょうぶ です か。// |
| 3 | だしだけですから、問題ないと思います。 | だし だけ です から、/ もんだい ない と おもいます。// |

### 必須回應

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| 申し訳ありません。重度の甲殻類アレルギーがあり、少量でも食べられません。 | もうしわけ ありません。/ じゅうど の こうかくるい アレルギー が あり、/ しょうりょう でも たべられません。// | 有嚴重甲殼類過敏，少量也不能吃。 |
| エキスやだしも避ける必要があります。別の料理をお願いできますか。 | エキス や だし も / さける ひつよう が あります。/ べつ の りょうり を おねがい できます か。// | 萃取物與高湯也需避開，可換一道嗎？ |

### 過關

- 不用 `苦手です` 淡化真正過敏。
- 明確說少量與高湯是否可接受。
- 健康安全優先，不因主管施壓而嘗試。

## Scenario 4 — 與通路商總經理延續閒聊

### 情境

對方說第一次來台灣，也喜歡登山。你要做到「相槌＋一個追問＋少量分享」，不能像問卷。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | 台湾に来るのは今回が初めてです。 | たいわん に くる の は / こんかい が はじめて です。// |
| 2 | 週末はよく山に登ります。 | しゅうまつ は / よく やま に のぼります。// |
| 3 | 最近は仕事が忙しくて、なかなか行けません。 | さいきん は しごと が いそがしくて、/ なかなか いけません。// |

### 回應範例

| 步驟 | 自然日文 | 假名讀法 |
|---|---|---|
| 接住 | 初めてでいらっしゃるんですね。 | はじめて で いらっしゃるん です ね。// |
| 追問 | 今回、特に行ってみたい場所はありますか。 | こんかい、/ とくに いって みたい ばしょ は / あります か。// |
| 分享 | 私も時々ハイキングに行きます。まだ初心者ですが、自然の中を歩くのが好きです。 | わたし も ときどき / ハイキング に いきます。/ まだ しょしんしゃ です が、/ しぜん の なか を あるく の が すき です。// |
| 體貼 | お忙しいのですね。また時間が取れるといいですね。 | おいそがしい の です ね。/ また じかん が とれる と いい です ね。// |

### Level 3 限制

對方提到忙碌，不要立即追問健康、家庭或公司內情；用同理句後讓對方決定是否繼續。

## Scenario 5 — `はい` 被當成獨家權同意 `[CONFIRM]`

### 情境

通路商說：「那就只交給我們銷售吧？」你下意識說了 `はい`，對方開始把它當成承諾。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | 当社だけに販売権をいただけますね。 | とうしゃ だけ に / はんばいけん を いただけます ね。// |
| 2 | 今、「はい」とおっしゃいましたよね。 | いま、/ はい と おっしゃいました よ ね。// |
| 3 | では、独占契約の準備を始めます。 | では、/ どくせん けいやく の じゅんび を / はじめます。// |

### 立即修正

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| 誤解を招いてしまい、申し訳ありません。今の「はい」は、お話を理解したという意味です。 | ごかい を まねいて しまい、/ もうしわけ ありません。/ いま の はい は、/ おはなし を りかい した と いう いみ です。// | 抱歉造成誤會，剛才的「是」只代表我理解。 |
| 独占権への同意ではありません。この条件は社内での確認が必要です。 | どくせんけん への ごうい では ありません。/ この じょうけん は / しゃない で の かくにん が ひつよう です。// | 並非同意獨家；這項需內部確認。 |
| 明日の会議で、確認項目と回答日をすり合わせさせてください。 | あした の かいぎ で、/ かくにん こうもく と かいとうび を / すりあわせ させて ください。// | 明天會議再核對確認項目與回覆日。 |

### 過關

- 當場修正，不等到隔天。
- 清楚說「不是同意」，不使用模糊的 `難しいと思います`。
- 不因尷尬而補上一個新的口頭承諾。

## Scenario 6 — 敏感、機密與競爭者話題

### 情境

對方在氣氛放鬆後詢問未公開價格、其他客戶名稱、競爭者缺點或政治立場。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | 実際の価格を、ここだけの話で教えてください。 | じっさい の かかく を、/ ここ だけ の はなし で / おしえて ください。// |
| 2 | どの大手企業がすでに採用していますか。 | どの おおて きぎょう が / すでに さいよう して います か。// |
| 3 | あの競合会社は信頼できないと思いませんか。 | あの きょうごう がいしゃ は / しんらい できない と / おもいません か。// |

### 安全回應

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 未公開價格 | 価格は `[CONFIRM]` のため、この場で非公式にはお答えできません。正式な回答を文書でお送りします。 | かかく は **かくにん が ひつよう** な ため、/ この ば で ひこうしき に は / おこたえ できません。/ せいしき な かいとう を ぶんしょ で おおくり します。// |
| 客戶機密 | 申し訳ありませんが、お客様に関する情報は、公開許可のある範囲でのみお答えします。 | もうしわけ ありません が、/ おきゃくさま に かんする じょうほう は、/ こうかい きょか の ある はんい で のみ / おこたえ します。// |
| 不貶競爭者 | 他社への評価ではなく、お客様の要件に合うかどうかで比較したいと考えています。 | たしゃ への ひょうか では なく、/ おきゃくさま の ようけん に あう か どうか で / ひかく したい と かんがえて います。// |
| 轉話題 | 公開できる範囲で、最近お客様が重視される点を伺ってもよろしいですか。 | こうかい できる はんい で、/ さいきん おきゃくさま が じゅうし される てん を / うかがっても よろしい です か。// |

## Scenario 7 — 付款政策不明 `[CONFIRM]`

### 情境

帳單送來，雙方都伸手。你不知道這餐是否已依公司政策核准招待。

| Level | 對方日文 | 假名讀法 |
|---|---|---|
| 1 | 本日は当社でお支払いします。 | ほんじつ は / とうしゃ で おしはらい します。// |
| 2 | いえ、ぜひこちらに払わせてください。 | いえ、/ ぜひ こちら に はらわせて ください。// |
| 3 | 今後の契約のためですから、遠慮しないでください。 | こんご の けいやく の ため です から、/ えんりょ しないで ください。// |

### 回應骨架

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 尚不確定 | ありがとうございます。双方の社内規定を確認したいのですが、お支払いはどのようにいたしましょうか。 | ありがとうございます。/ そうほう の しゃない きてい を かくにん したい の です が、/ おしはらい は どのよう に いたしましょう か。// |
| 不可接受招待 | お心遣いに感謝します。ただ、社内規定により、今回は各自で支払わせてください。 | おこころづかい に かんしゃ します。/ ただ、/ しゃない きてい に より、/ こんかい は かくじ で はらわせて ください。// |
| 對方已付且合規 | 本日はごちそうになり、ありがとうございました。次回はぜひ私どもに機会をいただければと思います。 | ほんじつ は ごちそう に なり、/ ありがとうございました。/ じかい は ぜひ わたしども に / きかい を いただければ と おもいます。// |

不以未來合約作為接受招待的理由。若政策不清楚，先依公司規範詢問負責人。

## ChatGPT Voice 演練指令

> 請扮演本章指定的日本企業總經理、副總或通路主管，全程使用自然商務日文。一次只說一句，等我說「以上です」才繼續。Level 1 使用表格原句；連續兩輪合格後進 Level 2，以不同說法追問；Level 3 加入勸酒、沉默、誤解「はい」、敏感問題或商務承諾壓力。不可鼓勵飲酒，不可虛構產品或商務資訊。我的答案若含未核准價格、折扣、獨家、付款或合約承諾，立即用繁體中文指出，讓我重答。每輪只糾正一個最影響理解的日文問題與一個禮儀／邊界問題。

## 餐敘評分表

每項 0–2 分，滿分 16 分。

| 項目 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 稱謂與語域 | 稱呼錯或過度隨便 | 偶有不自然 | 穩定使用安全敬體 |
| 聆聽與相槌 | 打斷或沒反應 | 有反應但單調 | 相槌自然且不誤作同意 |
| 追問 | 像審問或不回應 | 有一個普通追問 | 接住關鍵字自然追問 |
| 分享平衡 | 只談自己或只盤問 | 比例失衡 | 有聽、有問、有短分享 |
| 飲食安全 | 淡化過敏或勉強飲酒 | 表達但不夠清楚 | 明確限制並提出替代 |
| 商務邊界 | 餐桌上做未核准承諾 | 有保留但含糊 | `[CONFIRM]` 清楚且有下一步 |
| 敏感話題 | 八卦、貶抑或洩密 | 生硬拒絕 | 禮貌設界線並轉話題 |
| 收尾 | 突然離席或反覆推讓 | 有致謝 | 清楚告別並銜接後續 |

### 關卡

- Gate 1：Scenario 1–4 各達 12 分，且過敏／拒酒內容完全清楚。
- Gate 2：Scenario 5–8 各達 13 分，沒有 `[CONFIRM]` 越權。
- Final：連續 20 分鐘混合餐敘，至少完成三次自然追問、一次話題轉換與一次清楚收尾；全程不靠翻譯提示。
