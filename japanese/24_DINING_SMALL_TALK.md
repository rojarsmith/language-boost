# 商務餐敘與日常交流日文

餐敘的目標不是表演日文，而是讓對方感到被尊重、願意繼續對話，同時不在輕鬆氣氛中做出未核准承諾。讀法中的 `/` 是短停頓，`//` 是句尾。

## 四條安全原則

1. 不確定座位就問，不自行判斷上座、下座。
2. 相槌表示「我在聽」，正式同意必須另用完整句確認。
3. 飲食禁忌、過敏與不喝酒要提早、明確說，不必為健康與信仰辯解。
4. 價格、折扣、獨家、合約、招待費與付款方式都可能是 `[CONFIRM]`；餐桌上不即興承諾。

## 抵達、寄放物品與座位

座位安排會受包廂、主客關係與公司習慣影響。最安全做法是稍候並跟隨主人指示。

| 情境 | 自然日文 | 假名讀法 | 中文 |
|---|---|---|---|
| 抵達 | 本日はお招きいただき、ありがとうございます。 | ほんじつ は / おまねき いただき、/ ありがとうございます。// | 謝謝今天邀請。 |
| 準時會合 | お待たせしていませんか。 | おまたせ して いません か。// | 沒有讓您久等吧？ |
| 遲到 | お待たせしてしまい、申し訳ございません。 | おまたせ して しまい、/ もうしわけ ございません。// | 抱歉讓您久等。 |
| 問座位 | どちらに座ればよろしいでしょうか。 | どちら に すわれば / よろしい でしょう か。// | 我該坐哪裡呢？ |
| 主人指位後 | ありがとうございます。では、こちらに失礼します。 | ありがとうございます。/ では、/ こちら に しつれい します。// | 謝謝，那我坐這裡。 |
| 放行李 | 荷物はこちらに置いてもよろしいでしょうか。 | にもつ は こちら に おいても / よろしい でしょう か。// | 行李可放這裡嗎？ |

不要搶著坐最裡面或正中央，也不要為座位反覆推讓。等主人示意，一次確認即可。

## 飲食限制與過敏

真正的過敏要說清楚食材、嚴重程度與高湯／醬汁是否也要避開。不要只說 `苦手です`，那可能被理解為不喜歡，而不是不能吃。

| 需求 | 自然日文 | 假名讀法 |
|---|---|---|
| 先詢問 | 食物アレルギーがあります。注文の前に確認してもよろしいでしょうか。 | しょくもつ アレルギー が あります。/ ちゅうもん の まえ に / かくにん しても よろしい でしょう か。// |
| 嚴重甲殼類過敏 | 重度の甲殻類アレルギーがあります。エキスやだしも避ける必要があります。 | じゅうど の こうかくるい アレルギー が あります。/ エキス や だし も / さける ひつよう が あります。// |
| 輕微不耐 | 乳製品を多く取ると体調を崩します。少量であれば大丈夫です。 | にゅうせいひん を おおく とる と / たいちょう を くずします。/ しょうりょう で あれば / だいじょうぶ です。// |
| 素食 | 肉と魚を食べません。だしに使われている場合も避けたいです。 | にく と さかな を たべません。/ だし に つかわれて いる ばあい も / さけたい です。// |
| 宗教因素 | 宗教上の理由で、豚肉とアルコールを口にできません。調味料も確認していただけますか。 | しゅうきょうじょう の りゆう で、/ ぶたにく と アルコール を / くち に できません。/ ちょうみりょう も かくにん して いただけます か。// |
| 生食 | 生ものは控えています。十分に加熱した料理をお願いします。 | なまもの は ひかえて います。/ じゅうぶん に かねつ した りょうり を / おねがい します。// |
| 主人協助後 | ご配慮いただき、ありがとうございます。 | ごはいりょ いただき、/ ありがとうございます。// |

若過敏可能危及生命，應在訂位前以書面確認，不能只靠現場口說。

## 自然拒酒，不破壞氣氛

`結構です` 可能聽起來含糊或生硬。先致謝，再明確拒絕，立刻提出替代飲料。

| 情境 | 自然日文 | 假名讀法 | 中文 |

| 已喝夠 | ありがとうございます。私はここまでにして、次はお水をいただきます。 | ありがとうございます。/ わたし は ここ まで に して、/ つぎ は おみず を いただきます。// | 謝謝，我喝到這裡，接著喝水。 |

## 五層追問梯

不必全部用；選一層就好。

| 層次 | 自然日文 | 假名讀法 |
|---|---|---|
| 接住關鍵字 | **[京都]** ですか。そうなんですね。 | **[きょうと]** です か。/ そう なん です ね。// |
| 問亮點 | 特にどの点が印象に残りましたか。 | とくに / どの てん が いんしょう に のこりました か。// |
| 問原因 | それを始められたきっかけは何ですか。 | それ を はじめられた / きっかけ は なん です か。// |
| 問比較 | 台湾と日本では、何か違いがありますか。 | たいわん と にほん では、/ なにか ちがい が あります か。// |
| 問下一次 | 次に試してみたいことはありますか。 | つぎ に / ためして みたい こと は / あります か。// |

也要適量分享自己，避免變成訪問：

## 相槌不等於同意

| 相槌 | 假名讀法 | 功能與風險 |
|---|---|---|
| はい。 | はい。// | 通常表示「有聽到」，也可能被理解為同意；重大條件後不能只說這個。 |
| そうなんですね。 | そう なん です ね。// | 中性接話：「原來如此」。 |
| おっしゃる点は理解しました。 | おっしゃる てん は / りかい しました。// | 表示理解觀點，不等於接受條件。 |
| 勉強になります。 | べんきょう に なります。// | 表示受益，適合聽經驗分享。 |

需要阻止誤解時：

| 自然日文 | 假名讀法 | 中文 |
|---|---|---|
| お話は理解しましたが、合意については社内確認が必要です。 | おはなし は りかい しました が、/ ごうい に ついて は / しゃない かくにん が ひつよう です。// | 我理解內容，但同意仍需公司內部確認。 |
| 今の「はい」は、内容を理解したという意味です。条件への同意ではありません。 | いま の はい は、/ ないよう を りかい した と いう いみ です。/ じょうけん への ごうい では ありません。// | 剛才的「是」表示理解，不是同意條件。 |

## 避免或慎入的話題

不要主動切入政治、宗教辯論、歷史爭議、收入、婚姻生育、疾病、公司八卦、客戶機密、對競爭者的貶抑，或對國家與族群做概括評論。若對方主動提及，可尊重地聽，但不需要表態。

| 情境 | 自然日文 | 假名讀法 |
|---|---|---|
| 不熟悉 | その点については詳しくないため、軽々しく意見を申し上げないようにしています。 | その てん に ついて は / くわしく ない ため、/ かるがるしく いけん を もうしあげない よう に / して います。// |
| 轉話題 | もしよろしければ、最近の市場のお話も伺えますか。 | もし よろしければ、/ さいきん の しじょう の おはなし も / うかがえます か。// |
| 私人問題 | 個人的なことですので、詳しい話は控えさせてください。 | こじんてき な こと です ので、/ くわしい はなし は / ひかえさせて ください。// |
| 機密 | 申し訳ありませんが、その内容は公開情報の範囲でのみお答えします。 | もうしわけ ありません が、/ その ないよう は / こうかい じょうほう の はんい で のみ / おこたえ します。// |
| 商務條件 | 大切な条件ですので、明日の会議で正式に確認させてください。`[CONFIRM]` | たいせつ な じょうけん です ので、/ あした の かいぎ で / せいしき に かくにん させて ください。// |
