# 總經理／副總／高階經理人問答

高階主管通常不想聽功能清單。他們問的是價值、差異、風險、投資理由與下一步。每題先用「10 秒短答」直接回答；對方點頭或追問後，再加一段。所有產品範圍以 [產品事實表](00_PRODUCT_TRUTH.md) 為準。

## 回答骨架：接・答・據・界・追

1. **接**：`ご質問ありがとうございます。`
2. **答**：第一句直接回答。
3. **據**：最多兩個理由或證據。
4. **界**：需要時說清目前範圍。
5. **追**：給下一步、負責人與日期。

不要每題把五步全唸出來；只有複雜或高風險問題才用完整骨架。

## 12. AI機能のデータリスクは？ `[QUALIFY]`

> AIに送られるデータは何ですか。  
> エーアイ に おくられる データ は / なん です か。

> りよう する プロバイダー に よって ことなります。/ オープンルーター を えらぶ と、/ プロンプト、てんぷ がぞう、プロジェクト の スナップショット が / オープンルーター へ おくられます。/ オラマ を えらぶ と、/ おなじ ないよう が せってい した オラマ ホスト へ おくられます。/ ローカル で かんけつ すると いえる の は、/ その ホスト が この コンピューターじょう に ある ばあい だけ です。/ せいしき どうにゅう まえ に、/ せつぞくさき、データ ぶんるい、りよう モデル、ほじ じょうけん、しゃない ポリシー を / かくにん する ひつよう が あります。

補充：AI 不會操作 Deploy 或硬體；provider gate 只證明 capability，整體品質仍須逐案評估。

## Gate 4A

- 隨機 16 題中至少 13 題，第一句直接回答。
- 每個短答 10–20 秒，展開後仍在 35 秒內。
- 所有 `[CONFIRM]` 題零猜測。
- 每題只使用必要敬語，不因想說得高級而卡住。
- 能辨識正式問法與主管短問法。
