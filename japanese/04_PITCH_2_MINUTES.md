### 2. 客戶面對的問題

> 組み込みHMIの開発では、画面設計、動作ロジック、機器との通信、ファームウェアのビルドが、別々の工程やツールに分かれがちです。  
> そのため、実機で統合する段階になってから、問題が見つかることがあります。

讀法：

> くみこみ エイチ・エム・アイ の かいはつ では、/ がめん せっけい、/ どうさ ロジック、/ きき との つうしん、/ ファームウェア の ビルド が、/ べつべつ の こうてい や ツール に / わかれがち です。//  
> そのため、/ じっき で とうごう する だんかい に なって から、/ もんだい が みつかる こと が あります。//

中文意圖：描述一般流程摩擦，不聲稱已量測客戶節省多少成本。

### 3. 一個專案、五個步驟

> EDT HMI Studioは、その流れを一つのプロジェクトでつなぎます。  
> まず画面を設計し、次にロジックを定義します。  
> そして、機器との通信とタグを設定し、生成したアプリケーションをエミュレーターで確認します。  
> 最後に、ファームウェアをビルドして、対応ハードウェアへ書き込みます。

讀法：

> イー・ディー・ティー エイチ・エム・アイ スタジオ は、/ その ながれ を / ひとつ の プロジェクト で つなぎます。//  
> まず がめん を せっけい し、/ つぎ に ロジック を ていぎ します。//  
> そして、/ きき との つうしん と タグ を せってい し、/ せいせい した アプリケーション を / エミュレーター で かくにん します。//  
> さいご に、/ ファームウェア を ビルド して、/ たいおう ハードウェア へ かきこみます。//

### 4. 主要差異：生成程式的驗證

> エミュレーターは、生成されたCコードを実際のLVGLと一緒にコンパイルします。  
> 画面だけでなく、イベントやロジックを動かし、機器通信をシミュレーションして、実機に移る前に確認できます。

讀法：

> エミュレーター は、/ せいせい された シー コード を / じっさい の エル・ブイ・ジー・エル と いっしょ に / コンパイル します。//  
> がめん だけ で なく、/ イベント や ロジック を うごかし、/ きき つうしん を シミュレーション して、/ じっき に うつる まえ に / かくにん できます。//

### 5. 目前可說的範圍

> 現在のソースには、三つのボードプロファイルがあります。  
> 実装済みの主なシリアル通信経路では、Modbus RTUと設定可能なシリアルコマンドを利用できます。  
> 対応範囲では、アプリケーションコードを書かずに、画面設計から動作するファームウェアまで進められます。

讀法：

> げんざい の ソース には、/ みっつ の ボード プロファイル が あります。//  
> じっそうずみ の / おもな シリアル つうしん けいろ では、/ モドバス アール・ティー・ユー と / せってい かのう な シリアル コマンド を / りよう できます。//  
> たいおう はんい では、/ アプリケーション コード を かかず に、/ がめん せっけい から / どうさ する ファームウェア まで / すすめられます。//

### 6. 收尾與探索

> 重要なのは、個々の機能ではなく、同じプロジェクトが開発工程をつなぐことです。  
> まずは、お客様の対象機器、ボード、通信方式を伺い、最初の評価ケースを一緒に決めたいと考えています。

讀法：

> じゅうよう なの は、/ ここ の きのう では なく、/ おなじ プロジェクト が / かいはつ こうてい を つなぐ こと です。//  
> まず は、/ おきゃくさま の たいしょう きき、/ ボード、/ つうしん ほうしき を うかがい、/ さいしょ の ひょうか ケース を / いっしょ に きめたい と かんがえて います。//
