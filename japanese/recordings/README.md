# 口說錄音區

這個目錄用來保存個人練習錄音；正式教材不要求把錄音提交到版本控制。

## 命名規則

使用：`YYYY-MM-DD_dayNN_scenario_attemptNN.ext`

例如：`2026-09-02_day01_pitch30_attempt01.m4a`

`scenario` 建議使用：`pronunciation`、`pitch30`、`pitch2m`、`pitch5m`、`demo`、`executive_qa`、`channel_qa`、`technical_qa`、`dining`、`full_event`。

## 每次錄音後

1. 不剪接、不重錄，先保留第一次完整嘗試。
2. 在 `../scorecard.csv` 評分。
3. 在 `../error_log.csv` 只登記一個最影響理解或商務安全的錯誤。
4. 修正後再錄一次，檔名的 `attemptNN` 加一。
5. 隔天冷啟動再測；同一天重錄成功不等於通過 Gate。

錄音可能含姓名、客戶或商業資訊。分享前先確認內容與收件人，不要把未公開產品資訊放進公開連結。
