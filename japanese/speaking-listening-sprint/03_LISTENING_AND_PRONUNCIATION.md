# 聽力與發音的每日練法

讀得懂日文不代表聽得到詞的邊界。每次只練一段 15 至 40 秒、能取得逐字稿的音訊；先聽意思，再校正聲音，再練聽完回應。主教材採 [Irodori 入門官方教材與 MP3](https://www.irodori.jpf.go.jp/en/starter/pdf.html)，另有可免費註冊的 [線上課程](https://www.irodori-online.jpf.go.jp/)。[國際交流基金課程介紹](https://www.jpf.go.jp/j/kansai/clip/irodori-online/)

本目錄提供文字練習，沒有附製作好的錄音檔。生活聽力使用上述官方音訊；面試與商務的自製問句可請陪練者朗讀或錄製。文字朗讀工具可輔助辨詞，最後仍要換真人聲音驗收。

## 一段音訊的 30 分鐘

1. **3 分鐘初聽**：正常速度、不看字幕，最多兩次。只記「誰、想做什麼、關鍵條件」；不懂也先猜情境，不必逐字抄。
2. **5 分鐘核對**：看逐字稿，標出三至五個阻礙理解的詞。辨別是詞不懂，還是詞懂但聲音辨不出。
3. **7 分鐘分段重聽**：每次切一個意思單位，聽一句、暫停、複述。原速太難，可暫用約 0.8 倍或請陪練者放慢；結束前回原速。
4. **5 分鐘跟讀**：先聽完一句再模仿，熟了才延遲約一個短節拍跟著說。不要一開始勉強追整段。
5. **5 分鐘遮稿回應**：再播原速，先說你聽到的意圖，再以日文回答。若只是背出原句，還沒完成這一步。
6. **5 分鐘變化與紀錄**：由陪練者改一個日期、數量或否定，再問一次。隔天先用舊段落測一次，再選新段落。

選段時，若對照逐字稿後仍幾乎每句都無法理解，就改更短、更初階的材料。避免連續聽很久卻始終不能回答其中任何問題。

## 同一問題的不同問法

左欄先主動會用，右欄先學聽懂。不要只記某個關鍵詞就搶答；聽完整句，辨認問的是經驗、理由、做法還是限制。

| 意圖 | 基本問法與讀音 | 更正式或省略的問法與讀音 |
| --- | --- | --- |
| 自介 | 自己紹介をお願いします。／じこしょうかいを おねがいします | 簡単に経歴を教えてください。／かんたんに けいれきを おしえてください |
| 使用技術 | 何を使っていますか。／なにを つかって いますか | 主な技術スタックは何ですか。／おもな ぎじゅつすたっくは なんですか |
| 自己的責任 | 何を担当しましたか。／なにを たんとうしましたか | ご自身の役割は何でしたか。／ごじしんの やくわりは なんでしたか |
| 選擇理由 | なぜ、これを選びましたか。／なぜ これを えらびましたか | 採用した理由は何ですか。／さいようした りゆうは なんですか |
| 遇到困難 | 何が難しかったですか。／なにが むずかしかったですか | どんな課題がありましたか。／どんな かだいが ありましたか |
| 改善方法 | どうやって直しましたか。／どうやって なおしましたか | どのように対応しましたか。／どのように たいおうしましたか |
| 期限 | いつまでにできますか。／いつまでに できますか | 納期はいつですか。／のうきは いつですか |
| 經驗有無 | 使ったことがありますか。／つかったことが ありますか | 実務経験はありますか。／じつむけいけんは ありますか |
| 限制與風險 | 問題はありますか。／もんだいは ありますか | どんなリスクがありますか。／どんな りすくが ありますか |
| 需要協助 | 何か困っていますか。／なにか こまって いますか | サポートは必要ですか。／さぽーとは ひつようですか |

常見追問：「具体的には？」（ぐたいてきには，具體而言呢）、「それはなぜですか」（那是為什麼）、「他の方法は？」（ほかの ほうほうは，其他方法呢）、「例えば？」（たとえば，例如呢）。先辨認意圖，再答一個例子或一個理由。

## 先判斷詞尾與條件

| 聽到的句子 | 假名 | 必須分辨 |
| --- | --- | --- |
| できます。／できません。 | できます／できません | 可以／不可以 |
| 終わりました。／まだ終わっていません。 | おわりました／まだ おわって いません | 完成／尚未完成 |
| 明日までにお願いします。 | あしたまでに おねがいします | 最晚明天完成 |
| 明日からお願いします。 | あしたから おねがいします | 從明天開始 |
| 三時ではなく、四時です。 | さんじではなく よじです | 不是三點，是四點 |
| Aだけでなく、Bも必要です。 | えーだけでなく びーも ひつようです | A和B都需要 |

不要一聽到「できます」就判斷對方要求你完成。完整句若是「できますか」是詢問；若是「できません」意思相反。數字和否定一起聽。

## 數字與日期

| 類別 | 日文與讀音 | 練習 |
| --- | --- | --- |
| 常見時點 | 四時よじ、七時しちじ、九時くじ | 聽到四時，不復述成四時間 |
| 分鐘 | 一分いっぷん、六分ろっぷん、十分じゅっぷん | 時點與所需時間分開，例如三時十分與十分かかります |
| 金額 | 百ひゃく、三百さんびゃく、六百ろっぴゃく、八百はっぴゃく、千せん、三千さんぜん、一万いちまん | 1500円＝せんごひゃくえん；15000円＝いちまんごせんえん |
| 日期 | 一日ついたち、二日ふつか、三日みっか、四日よっか、八日ようか、十日とおか、二十日はつか | 期限念完整月份及日期；一日作日期與一天いちにちは不同 |
| 月份 | 四月しがつ、七月しちがつ、九月くがつ | 特別練這三個，不套用數字的另一讀法 |
| 相對時間 | 今日きょう、明日あした、明後日あさって、来週らいしゅう | 對方說来週時再確認實際日期 |

確認句：「十一月四日の午後三時、日本時間ですね。」（じゅういちがつ よっかの ごご さんじ にほんじかんですね，11 月 4 日下午 3 點，日本時間，對嗎）。跨國面試要確認時區；不要只說「三點」。

## 發音先修會改變意思的項目

五十音熟悉後，重點是拍數與詞的實際聲音。以下例子是發音練習，不是要求一次背完所有詞。

| 重點 | 對照 | 練法 |
| --- | --- | --- |
| 長音 | ビル 大樓／ビール 啤酒；おばさん 阿姨／おばあさん 奶奶 | 長音多一拍，錄音時不吞掉 |
| 促音 | きて 來／きって 郵票；いって 說或去的て形 | 小っ保留一拍停頓，不加母音 |
| 拗音 | きゃ 是一拍，きや 是兩拍；しゅ 與しゆ | 以原音模仿，不拆成兩個母音 |
| 撥音 | さん（三）含さ、ん兩拍 | 保留ん的一拍，不與後一音混掉 |
| 技術詞 | サーバー、データ、レビュー、セキュリティ | 依日文拍數念，不能只套英文發音 |

ます、です的句尾母音有時較弱，不必強行加重；先確保整句能被理解。高低音調以標準音訊或教師校正，不用在第一週追求每個詞完全準確。

## 聽不懂時的修復階梯

1. 問題沒聽清：もう一度言っていただけますか。（もういちど いって いただけますか，能再說一次嗎）
2. 詞不懂：「納期」はどういう意味ですか。（のうきは どういう いみですか，「交期」是什麼意思）
3. 句子太長：一つずつ質問していただけますか。（ひとつずつ しつもんして いただけますか，能逐題詢問嗎）
4. 大致理解：私の担当についての質問ですか。（わたしの たんとうについての しつもんですか，是問我負責的部分嗎）
5. 技術細節超出能力：英語で補足してもよろしいでしょうか。（えいごで ほそくしても よろしいでしょうか，能用英文補充嗎）

第一次就能理解最好；修復成功也算完成任務，但要記下用過幾次。若一直請重說卻仍不知道問題是什麼，就不能把該情境評為已掌握。
