# 日本日常生活的雙向對話

每個場景至少練六回合：提出需求、聽對方選項、回答、確認、處理一個變更、收尾。下面的句子是自製練習；括號是假名讀音。先遮住中文聽陪練者念對方台詞，再回答，不能只練自己要說的部分。

## 點餐與付款

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | これを一つお願いします。／これを ひとつ おねがいします | 這個請給我一份 |
| 店員 | 店内でお召し上がりですか。お持ち帰りですか。／てんないで おめしあがりですか。おもちかえりですか | 內用還是外帶 |
| 你 | 店内でお願いします。／てんないで おねがいします | 內用，謝謝 |
| 店員 | お飲み物はいかがですか。／おのみものは いかがですか | 要飲料嗎 |
| 你 | 水をお願いします。／みずを おねがいします | 請給我水 |
| 你 | カードで払えますか。／かーどで はらえますか | 可以刷卡嗎 |
| 店員 | 現金のみです。／げんきんのみです | 只收現金 |
| 你 | 分かりました。現金で払います。／わかりました。げんきんで はらいます | 明白，我付現金 |

替換：外帶＝持ち帰りでお願いします（もちかえりで おねがいします）；兩份＝二つ（ふたつ）。「結構です／けっこうです」可能隨情境表示婉拒或足夠，初期要拒絕可說「いりません。ありがとうございます」（不用，謝謝），比較明確。

任務：店員改成餐點售完「売り切れです」（うりきれです），你需改點別的，不能繼續照原稿回答。

## 點餐與金額確認｜聽明細，找出多收的原因

**你的訂單。** 三明治一份六百円、普通茶一杯二百円，均為含稅練習價。先說「サンドイッチを一つと、普通サイズの紅茶を一杯お願いします」。夥伴暗選一張卡，用日文回讀。兩張卡都是一千円，聽完再指出要改哪一項。

| 店員回讀 | 你可以怎麼接 |
| --- | --- |
| A ·「サンドイッチがお一つと、紅茶が二杯で、千円です。」 | 「すみません、紅茶は一杯だけです。全部で八百円ですね。」 |
| B ·「サンドイッチがお一つと、大きいサイズの紅茶が一杯で、千円です。紅茶は四百円です。」 | 「二百円の普通サイズでお願いします。これで八百円ですか。」 |

**換一筆自己算。** 這次點一份三明治和兩杯茶，其中一杯換成大杯。請夥伴回讀訂單，你用「普通サイズが一杯、大きいサイズが一杯ですね」核對數量，再自己報出總額。答案是一千二百円（せんにひゃくえん）。一杯讀作「いっぱい」，二杯讀作「にはい」。

### 進階情境｜共點的餐點怎麼分帳？

兩人用餐，價格均含稅。你要六百円的湯，朋友要一千円的義大利麵，共點四百円的沙拉。說出訂單，再詢問分帳方式。

**開場示範。** 「スープとパスタを一つずつお願いします。サラダも一つ、二人で分けます。会計は別々にできますか。」

**追問與回應。** 「合計を半分ずつでよろしいですか。」→「サラダ代だけ半分ずつでお願いします。私は八百円、友人は千二百円ですね。」

**換條件。** 朋友說「サラダ代は私が払います」。重算後向店員確認：「では、私は六百円、友人は千四百円ですね」。兩筆相加應仍是二千円。

### 進階情境｜套餐已含飲料，帳單怎麼核對？

午餐套餐一千二百円，附小杯紅茶，換大杯加一百円，均含稅。先說「ランチセットをお願いします。飲み物は小さい紅茶でお願いします」。夥伴扮店員，回讀帳單。

| 店員說 | 你可以怎麼接 |
| --- | --- |
| 「セットが千二百円、紅茶が三百円です。」 | 「小さい紅茶はセットに付いていますよね。この三百円は何の料金でしょうか。」若店員取消重複費用，再確認「では、千二百円ですね。」 |
| 換條件：你點了大杯。「サイズ変更で百円追加です。」 | 「大きいサイズとの差額ですね。全部で千三百円ですか。」 |

**盲測。** 請夥伴換一個杯型，只用日文報出明細。先說明喝到哪一杯，再核對差額（さがく）與合計（ごうけい）。

## 交通與問路

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | この電車は新宿に行きますか。／この でんしゃは しんじゅくに いきますか | 這班車會到新宿嗎 |
| 對方 | いいえ、次の電車です。／いいえ つぎの でんしゃです | 不會，是下一班 |
| 你 | 何番線ですか。／なんばんせんですか | 在第幾月台 |
| 對方 | 三番線です。／さんばんせんです | 第三月台 |
| 你 | 乗り換えは必要ですか。／のりかえは ひつようですか | 需要轉車嗎 |
| 對方 | 一回、乗り換えます。／いっかい のりかえます | 轉一次車 |
| 你 | 次の電車で、一回乗り換えるんですね。／つぎの でんしゃで いっかい のりかえるんですね | 搭下一班，轉一次，對嗎 |

以上地點與路線是練習設定，不是真實交通指引。任務：改成「乗り換えはありません」（のりかえは ありません，不用轉車）。先聽完整回答再行動。

另備問路句：「すみません。駅はどちらですか」（すみません えきは どちらですか，請問車站在哪邊）。聽懂右／みぎ、左／ひだり、まっすぐ／直走，再用手勢或地圖確認。

## 租屋條件確認｜問清楚每月費用與開通日期

你想在下個月三日入住，也需要網路。請夥伴扮帶看人員，逐句念出左欄的虛構條件。先用日文確認，再看右欄核對。

| 帶看人員說 | 你可以怎麼確認 |
| --- | --- |
| 「ネット代は月三千円です。最初に工事費が五千円かかります。」 | 「毎月三千円で、工事費の五千円は最初の一回だけですか。」 |
| 「入居は来月の三日からです。ネットが使えるのは六日からです。」 | 「三日に入居して、六日からネットが使えるんですね。料金と日付をメールで送っていただけますか。」 |

**條件更正。** 對方查過後說「失礼しました。六日から工事の予約ができます。工事の日はまだ決まっていません」。聽到 予約（よやく）後，用短句確認「六日は予約ができる日ですね。工事の日はいつ分かりますか」。回聽時分別記下入住日、可預約日、尚待確認的日期。三日讀作「みっか」，六日讀作「むいか」。

### 進階情境｜點交表寫「鍵二本」，信封裡卻只有一把

**房客卡。** 點交時，確認表上已交付的鑰匙數量是二本（にほん），但你只拿到一本（いっぽん）。請夥伴扮管理員，逐輪念左欄，你先口頭描述看到的差異，再追問下一步。

| 管理員說 | 房客可以怎麼接 |
| --- | --- |
| 「鍵の本数を確認していただけますか。」 | 「確認表には二本とありますが、封筒には一本しか入っていません。一緒に確認していただけますか。」 |
| 「そうですね。私が一本に訂正して、今日中に確認表をメールでお送りします。」 | 「ありがとうございます。もう一本はどうなりますか。」 |
| 「事務所に確認して、明日の正午までにご連絡します。」 | 「訂正後の確認表は今日中に届いて、もう一本については明日の正午までにご連絡いただける、ということですね。」 |

**換條件。** 管理員改口說「もう一本ありました。どうぞ」，並把鑰匙交給你。請重新數一次，再說「これで二本受け取りました」。第一次的回覆裡，正午（しょうご）是哪一件事的期限？請聽者用「連絡する」回答，再指出第二把鑰匙何時能拿到是否已經確定。

### 進階情境｜能先放箱子，也能先入住嗎？

**房客卡。** 你週六入住，週五想先放兩箱行李。管理員說「金曜日なら、段ボール箱を二箱までお預かりできます」。請問「どちらに持っていけばいいですか。料金はかかりますか」。夥伴回「午後五時より前に事務所にお持ちください。無料です。金曜日はまだ部屋を清掃しています」。

**讀回安排。** 「金曜日の午後五時より前に、事務所に二箱ですね。部屋の鍵は土曜日の朝に受け取るということでよろしいですか。」留意管理員說「預かる」（あずかる，代為保管），房客說「預ける」（あずける，寄放）。

**換條件。** 司機只能五點半到。先說明「到着は午後五時半になりそうです」，再問「土曜日の朝に持っていくことはできますか」。管理員確認後，才向司機重述最後安排。

## 閒聊與接話

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 對方 | 日本は初めてですか。／にほんは はじめてですか | 第一次來日本嗎 |
| 你 | はい、初めてです。／はい はじめてです | 是，第一次；依事實改答 |
| 你 | この辺でおすすめのお店はありますか。／このへんで おすすめの おみせは ありますか | 附近有推薦的店嗎 |
| 對方 | 駅の近くにあります。／えきの ちかくに あります | 車站附近有 |
| 你 | どんな料理ですか。／どんな りょうりですか | 是什麼料理 |
| 你 | そうなんですね。ありがとうございます。／そうなんですね ありがとうございます | 原來如此，謝謝 |
| 你 | 休日は何をしていますか。／きゅうじつは なにを して いますか | 放假都做什麼 |

每次「そうなんですね」後接一個相關問題，避免只有相槌。若對方回答「登山が好きです」（とざんが すきです，喜歡登山），可問「よく行きますか」（よく いきますか，常去嗎）。

## 同事閒聊｜聽到「そろそろ」時怎麼接

同事說「今日はいつもと違う道を通ってきました」（今天走了另一條路來）。你先問「どうでしたか」。夥伴從下表選一張卡念出來，你聽完再接一句。

| 同事回覆卡 | 可以怎麼接 |
| --- | --- |
| A ·「少し遠いですが、川沿いを歩けるんです。」 | 「いいですね。私はいつもバスです。朝の川沿いは静かですか。」 |
| B ·「よかったですよ。あ、そろそろ会議なので、行きますね。」 | 「はい、また後で。」 |

**聽力線索。** 川沿い（かわぞい）是沿河一帶，可以順著這個細節提問。B 卡的「そろそろ会議なので」表示快到開會時間，這時用一句道別就能讓同事離開。

**交換角色。** 換你趕時間，同事問「これからコーヒーを買いに行きませんか」。用「ありがとうございます。もうすぐ会議なので、今日はちょっと」婉拒。請夥伴只用一句話接住，例如「分かりました。また今度」。再換回 A 卡，把問題改成想知道沿路風景如何。

### 進階情境｜只聽到「屋内に移った」，怎麼加入三人對話？

午休時，你只聽到森說「屋内に移ったんですよ」（改到室內了）。等森說完，先問你漏掉的部分。請夥伴扮森和林，或三人各選一角。

1. 問話題：「途中からで、すみません。何が屋内に移ったんですか。」森說「金曜の朝市です。おいしいお茶のお店を見つけました」。你接「お茶ですか。何を飲んだんですか」。
2. 林說「私も先週行きました」。順著林自己提到的經驗，邀他加入：「そうなんですね。何か気になるお店はありましたか。」等他回覆，再決定接誰的話。

| 林任選一句 | 你可以怎麼接 |
| --- | --- |
| 「ミントティーを買いました。」 | 「いいですね。どんな味でしたか。」 |
| 「今日は聞いてますね。森さん、続き、どうぞ。」 | 「はい。森さん、お茶はいかがでしたか。」 |

**換題再試。** 改聊週末書展，開場只說「二階に移ったそうですよ」。遮住對話，問清楚移到二樓的是什麼活動，再根據同事透露的細節接話。途中（とちゅう）指中途，朝市（あさいち）是早市。回聽時確認：同事說想旁聽後，你是否讓原先說話的人自然接下去？

### 進階情境｜隨口說下次去，算約好週五了嗎？

午休時你說「今度、あのラーメン屋さんに行きたいですね」。同事拿起手機回「じゃあ、金曜日で予約しておきますね」。你想去，但週四下午才知道週五是否有空。先遮住示範，在同事訂位前接話。

> 「ぜひ行きたいです。ただ、金曜日はまだ予定が分からないので、予約は少し待ってもらえますか。木曜日の午後に返事をします。」

**同事選一張卡。** A：「分かりました。木曜日に教えてください。」確認自己會主動回覆。B：「今日中に人数を伝えないといけないんです。」若仍不能確定，可說「それなら、今回は私を人数に入れずに予約してください。ありがとうございます」。交換角色，再問一次誰已確定參加、何時要回覆。

## 說明不理解與需要協助

「日本語がまだよく分かりません。ゆっくりお願いします。」（にほんごが まだ よく わかりません。ゆっくり おねがいします，我還不太懂日文，請慢一點。）

「紙に書いていただけますか。」（かみに かいて いただけますか，可以寫在紙上嗎。）

「近くの病院はどこですか。」（ちかくの びょういんは どこですか，附近醫院在哪裡。）

這些句子用來提出需求。對方回覆若包含金額、日期、樓層或地址，要復述資訊或請寫下，不能只點頭。

## 本文件的驗收

隨機選三個場景，由陪練者改一個條件。每場六回合，完成需求、聽懂至少一項選擇、處理變更並確認結果。若聽到熟悉詞就答原稿，記為未完成，翌日練那個分岔。
