# 日本日常生活的雙向對話

每個場景至少練六回合：提出需求、聽對方選項、回答、確認、處理一個變更、收尾。下面的句子是自製練習；括號是假名讀音。先遮住中文聽陪練者念對方台詞，再回答，不能只練自己要說的部分。

## 點餐與付款

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | これを一つお願いします。／これを ひとつ おねがいします | 這個請給我一份 |
| 店員 | 店内でお召し上がりですか。お持ち帰りですか。／てんないで おめしあがりですか。おもちかえりですか | 內用還是外帶 |
| 你 | 店内でお願いします。／てんないで おねがいします | 內用，謝謝 |
| 店員 | お飲み物はいかがですか。／おのみものは いかがですか | 要飲料嗎 |
| 你 | 水をお願いします。／みずを おねがいします | 請給我水 |
| 你 | カードで払えますか。／かーどで はらえますか | 可以刷卡嗎 |
| 店員 | 現金のみです。／げんきんのみです | 只收現金 |
| 你 | 分かりました。現金で払います。／わかりました。げんきんで はらいます | 明白，我付現金 |

替換：外帶＝持ち帰りでお願いします（もちかえりで おねがいします）；兩份＝二つ（ふたつ）。「結構です／けっこうです」可能隨情境表示婉拒或足夠，初期要拒絕可說「いりません。ありがとうございます」（不用，謝謝），比較明確。

任務：店員改成餐點售完「売り切れです」（うりきれです），你需改點別的，不能繼續照原稿回答。

## 購物與便利商店

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | 充電器はありますか。／じゅうでんきは ありますか | 有充電器嗎 |
| 店員 | こちらです。／こちらです | 在這邊 |
| 你 | これはいくらですか。／これは いくらですか | 這個多少錢 |
| 店員 | 千五百円です。／せんごひゃくえんです | 1500 日圓 |
| 店員 | 袋は必要ですか。／ふくろは ひつようですか | 需要袋子嗎 |
| 你 | 袋はいりません。／ふくろは いりません | 不需要袋子 |
| 店員 | 温めますか。／あたためますか | 要加熱嗎 |
| 你 | はい、お願いします。／はい おねがいします | 好，麻煩了 |

任務：把價格改成 15000 日圓，把問題改為「レシートは必要ですか」（れしーとは ひつようですか，需要收據嗎）。需辨認對方實際問的物品。

## 交通與問路

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | この電車は新宿に行きますか。／この でんしゃは しんじゅくに いきますか | 這班車會到新宿嗎 |
| 對方 | いいえ、次の電車です。／いいえ つぎの でんしゃです | 不會，是下一班 |
| 你 | 何番線ですか。／なんばんせんですか | 在第幾月台 |
| 對方 | 三番線です。／さんばんせんです | 第三月台 |
| 你 | 乗り換えは必要ですか。／のりかえは ひつようですか | 需要轉車嗎 |
| 對方 | 一回、乗り換えます。／いっかい のりかえます | 轉一次車 |
| 你 | 次の電車で、一回乗り換えるんですね。／つぎの でんしゃで いっかい のりかえるんですね | 搭下一班，轉一次，對嗎 |

以上地點與路線是練習設定，不是真實交通指引。任務：改成「乗り換えはありません」（のりかえは ありません，不用轉車）。先聽完整回答再行動。

另備問路句：「すみません。駅はどちらですか」（すみません えきは どちらですか，請問車站在哪邊）。聽懂右／みぎ、左／ひだり、まっすぐ／直走，再用手勢或地圖確認。

## 飯店與設備問題

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | 予約した[名前]です。／よやくした[なまえ]です | 我是預約的＿＿ |
| 櫃台 | パスポートをお願いします。／ぱすぽーとを おねがいします | 請提供護照 |
| 你 | チェックアウトは何時ですか。／ちぇっくあうとは なんじですか | 幾點退房 |
| 櫃台 | 午前十時です。／ごぜん じゅうじです | 上午十點 |
| 你 | 部屋のWi-Fiがつながりません。／へやの わいふぁいが つながりません | 房間 Wi-Fi 連不上 |
| 你 | 確認していただけますか。／かくにんして いただけますか | 能幫我確認嗎 |
| 櫃台 | 少々お待ちください。／しょうしょう おまちください | 請稍等 |

任務：設備改成「エアコンが動きません」（えあこんが うごきません，冷氣不運作），你要描述實際問題，不只說「壞了」。

## 預約與更改時間

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 你 | 明日の午後、予約できますか。／あしたの ごご よやくできますか | 明天下午可以預約嗎 |
| 對方 | 午後は空いていません。午前十時なら大丈夫です。／ごごは あいて いません。ごぜん じゅうじなら だいじょうぶです | 下午沒空位，上午十點可以 |
| 你 | 午前十時でお願いします。／ごぜん じゅうじで おねがいします | 請安排上午十點 |
| 你 | 日付と時間を確認してもいいですか。／ひづけと じかんを かくにんしても いいですか | 可以確認日期與時間嗎 |
| 你 | 予約を変更したいです。／よやくを へんこうしたいです | 我想改預約 |
| 你 | 文字で送っていただけますか。／もじで おくって いただけますか | 能用文字傳給我嗎 |

任務：對方把明天改為明後日，你要指出差異並確認。電話缺少表情與畫面，先練面對面，熟了再做純音訊。

## 閒聊與接話

| 角色 | 日文及讀音 | 中文 |
| --- | --- | --- |
| 對方 | 日本は初めてですか。／にほんは はじめてですか | 第一次來日本嗎 |
| 你 | はい、初めてです。／はい はじめてです | 是，第一次；依事實改答 |
| 你 | この辺でおすすめのお店はありますか。／このへんで おすすめの おみせは ありますか | 附近有推薦的店嗎 |
| 對方 | 駅の近くにあります。／えきの ちかくに あります | 車站附近有 |
| 你 | どんな料理ですか。／どんな りょうりですか | 是什麼料理 |
| 你 | そうなんですね。ありがとうございます。／そうなんですね ありがとうございます | 原來如此，謝謝 |
| 你 | 休日は何をしていますか。／きゅうじつは なにを して いますか | 放假都做什麼 |

每次「そうなんですね」後接一個相關問題，避免只有相槌。若對方回答「登山が好きです」（とざんが すきです，喜歡登山），可問「よく行きますか」（よく いきますか，常去嗎）。

## 說明不理解與需要協助

「日本語がまだよく分かりません。ゆっくりお願いします。」（にほんごが まだ よく わかりません。ゆっくり おねがいします，我還不太懂日文，請慢一點。）

「紙に書いていただけますか。」（かみに かいて いただけますか，可以寫在紙上嗎。）

「近くの病院はどこですか。」（ちかくの びょういんは どこですか，附近醫院在哪裡。）

這些句子用來提出需求。對方回覆若包含金額、日期、樓層或地址，要復述資訊或請寫下，不能只點頭。

## 本文件的驗收

隨機選三個場景，由陪練者改一個條件。每場六回合，完成需求、聽懂至少一項選擇、處理變更並確認結果。若聽到熟悉詞就答原稿，記為未完成，翌日練那個分岔。
