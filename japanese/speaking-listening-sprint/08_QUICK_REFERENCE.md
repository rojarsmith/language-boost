# 面試與會議前的日文速查

先練前六句，再練其餘。看中文意圖能說出日文，才算可使用；實際面試是否能看筆記，以招募方規則為準。

## 六句聽力修復

| 日文 | 假名 | 中文 |
| --- | --- | --- |
| もう一度言っていただけますか。 | もういちど いって いただけますか | 能再說一次嗎 |
| もう少しゆっくり話していただけますか。 | もうすこし ゆっくり はなして いただけますか | 能再說慢一點嗎 |
| 一つずつ質問していただけますか。 | ひとつずつ しつもんして いただけますか | 能逐題詢問嗎 |
| 「＿＿」はどういう意味ですか。 | 「＿＿」は どういう いみですか | ＿＿是什麼意思 |
| ＿＿という理解でよろしいでしょうか。 | ＿＿という りかいで よろしいでしょうか | 我的理解是＿＿，正確嗎 |
| 英語で補足してもよろしいでしょうか。 | えいごで ほそくしても よろしいでしょうか | 能用英文補充嗎；只在允許時使用 |

## 自己的三個故事

| 類別 | 提示關鍵字，只填真實資訊 |
| --- | --- |
| 成功專案 | 問題＿＿／我的部分＿＿／方法＿＿／結果與依據＿＿ |
| 失敗改善 | 問題＿＿／我的責任＿＿／修正＿＿／預防＿＿ |
| 團隊合作 | 共同目標＿＿／意見差異＿＿／討論或驗證＿＿／決定＿＿ |

答題順序：聽完→必要時確認→結論→理由→例子→接受追問。關鍵時間、否定、金額與責任要說準。

## 六個生活意圖

點餐：これを一つお願いします（これを ひとつ おねがいします，這個一份）。

付款：カードで払えますか（かーどで はらえますか，可以刷卡嗎）。

交通：この電車は＿＿に行きますか（この でんしゃは ＿＿に いきますか，這班車去＿＿嗎）。

問價：いくらですか（多少錢）。

確認：明日の午後三時ですね（あしたの ごご さんじですね，是明天下午三點，對嗎）。

求助：紙に書いていただけますか（かみに かいて いただけますか，能寫在紙上嗎）。
