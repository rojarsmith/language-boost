# 上台需要的最小日文文法

## 這不是完整日文課

目標是用少量、穩定、可替換的句型完成產品介紹、主管問答與餐敘。先把每個句型當成一整塊工具，不要在台上臨時做複雜變化。

所有產品內容仍以 [00_PRODUCT_TRUTH.md](../japanese/00_PRODUCT_TRUTH.md) 為準。本章的產品句只是句型示範，不代表未經確認就能直接對外宣稱。

## 先記三個特殊讀音

- 助詞 は 念「わ」。
- 助詞 へ 念「え」。
- 助詞 を 念「お」。

> この製品は、組み込み機器向けです。

全假名：この せいひんは、くみこみききむけです。

停頓：この せいひんは / くみこみききむけです。//

## 句型 1：A 是 B

結構：**A は B です。**

> EDT HMI Studioは、組み込み機器向けの開発環境です。

全假名：イーディーティー・エイチエムアイ・スタジオは、くみこみききむけの かいはつかんきょうです。

停頓：イーディーティー・エイチエムアイ・スタジオは / くみこみききむけの / かいはつかんきょうです。//

用途：一句定位產品。不要先堆背景故事。

否定：**A は B ではありません。**

> こちらは、現行版の機能ではありません。

全假名：こちらは、げんこうばんの きのうでは ありません。

停頓：こちらは / げんこうばんの きのうでは ありません。//

## 句型 2：做某個動作

結構：**A を 動詞ます。**

> 画面を設計します。

全假名：がめんを せっけいします。

停頓：がめんを / せっけいします。//

可替換：

- 設定を確認します。  
  全假名：せっていを かくにんします。
- 結果をご説明します。  
  全假名：けっかを ごせつめいします。
- 条件を整理します。  
  全假名：じょうけんを せいりします。

## 句型 3：用 A 做 B

結構：**A で B します。** 此處的 で 表示工具或環境。

> エミュレーターで動作を確認します。

全假名：エミュレーターで どうさを かくにんします。

停頓：エミュレーターで / どうさを かくにんします。//

> この画面で設定内容をご説明します。

全假名：この がめんで せっていないようを ごせつめいします。

停頓：この がめんで / せっていないようを / ごせつめいします。//

## 句型 4：適用對象與方向

結構：**A 向けです。** 表示面向某類使用者或用途。

> この説明は、販売代理店向けです。

全假名：この せつめいは、はんばいだいりてんむけです。

停頓：この せつめいは / はんばいだいりてんむけです。//

結構：**A へ B します。** 表示方向；助詞 へ 念「え」。

> 対応ハードウェアへデプロイします。

全假名：たいおうハードウェアへ デプロイします。

停頓：たいおうハードウェアへ / デプロイします。//

## 句型 5：能做 A

結構：**A ことができます。**

> 一つのプロジェクトで設定を管理することができます。

全假名：ひとつの プロジェクトで せっていを かんりすることが できます。

停頓：ひとつの プロジェクトで / せっていを かんりすることが / できます。//

口說時可更短：

> 一つのプロジェクトで管理できます。

全假名：ひとつの プロジェクトで かんりできます。

只有產品事實表確認的能力才能使用「できます」。不確定時改說：

> 対応可否を確認する必要があります。

全假名：たいおうかひを かくにんする ひつようが あります。

停頓：たいおうかひを / かくにんする ひつようが あります。//

## 句型 6：支援或對應 A

結構：**A に対応しています。**

> 現行版は、この構成に対応しています。

全假名：げんこうばんは、この こうせいに たいおうしています。

停頓：げんこうばんは / この こうせいに / たいおうしています。//

明確否定：

> 現時点では、この構成に対応していません。

全假名：げんじてんでは、この こうせいに たいおうしていません。

有限定條件：

> 構成によります。対象を確認する必要があります。

全假名：こうせいに よります。たいしょうを かくにんする ひつようが あります。

停頓：こうせいに よります。/ たいしょうを / かくにんする ひつようが あります。//

## 句型 7：因為 A，所以 B

初學先用兩句，最安全：

> 設定を一つの流れで確認できます。そのため、検証しやすくなります。

全假名：せっていを ひとつの ながれで かくにんできます。そのため、けんしょうしやすく なります。

停頓：せっていを / ひとつの ながれで / かくにんできます。/ そのため / けんしょうしやすく なります。//

也可用 ので：

> 正確な情報が手元にないので、確認してから回答します。

全假名：せいかくな じょうほうが てもとに ないので、かくにんしてから かいとうします。

停頓：せいかくな じょうほうが / てもとに ないので / かくにんしてから / かいとうします。//

## 句型 8：依順序說明

結構：**まず A。次に B。最後に C。**

> まず、画面を設計します。次に、機器通信を設定します。最後に、対応ハードウェアへデプロイします。

全假名：まず、がめんを せっけいします。つぎに、ききつうしんを せっていします。さいごに、たいおうハードウェアへ デプロイします。

停頓：まず / がめんを せっけいします。/ つぎに / ききつうしんを せっていします。/ さいごに / たいおうハードウェアへ / デプロイします。//

常用路標：

- まず：首先。全假名：まず。
- 次に：接著。全假名：つぎに。
- その後：之後。全假名：そのあと。
- ここで：在這裡。全假名：ここで。
- 最後に：最後。全假名：さいごに。

忘記中間一段時，直接說「次に」跳到下一段，不要從頭重來。

## 句型 9：列舉，但不暗示全部都有

結構：**A や B など。** 「や」是舉例，不是完整清單。

> 画面設計やロジック設定、通信設定などを、一つのプロジェクトで管理します。

全假名：がめんせっけいや ロジックせってい、つうしんせっていなどを、ひとつの プロジェクトで かんりします。

停頓：がめんせっけいや / ロジックせってい / つうしんせっていなどを / ひとつの プロジェクトで / かんりします。//

若清單確定完整，才用 **A と B**。台上不確定時優先用 **や／など**。

## 句型 10：比較與差異

結構：**A と B では、C が異なります。**

> エミュレーターと実機では、確認できる範囲が異なります。

全假名：エミュレーターと じっきでは、かくにんできる はんいが ことなります。

> ボードによって、対応機能が異なります。

全假名：ボードに よって、たいおうきのうが ことなります。

停頓：ボードに よって / たいおうきのうが / ことなります。//

「比競品更好」需要證據。沒有核准資料時，不直接比較，改問：

> どの点を重視されていますか。

全假名：どの てんを じゅうしされていますか。

## 句型 11：條件不同，答案不同

結構：**A 場合は、B。**

> 対象ボードが決まっている場合は、対応範囲を確認できます。

全假名：たいしょうボードが きまっている ばあいは、たいおうはんいを かくにんできます。

停頓：たいしょうボードが / きまっている ばあいは / たいおうはんいを / かくにんできます。//

結構：**A によって異なります。** 適合用在需求、板卡或合約條件不同的回答。

> 条件によって異なりますので、要件を確認させてください。

全假名：じょうけんに よって ことなりますので、ようけんを かくにんさせて ください。

## 句型 12：提出下一步

結構：**A はいかがでしょうか。** 比「A しましょう」柔和，適合對客戶提案。

> まず一つの用途で検証するのはいかがでしょうか。

全假名：まず ひとつの ようとで けんしょうするのは いかがでしょうか。

停頓：まず / ひとつの ようとで / けんしょうするのは / いかがでしょうか。//

結構：**A をご提案します。** 用於明確提案。

> 対象ボードと通信方式を決めて、短い技術検証を行うことをご提案します。

全假名：たいしょうボードと つうしんほうしきを きめて、みじかい ぎじゅつけんしょうを おこなうことを ごていあんします。

## 句型 13：請求、允許與柔和指示

直接請求 **A してください** 對客戶有時偏強，商務場合優先用：**A していただけますか。**

> 対象機器を教えていただけますか。

全假名：たいしょうききを おしえて いただけますか。

取得允許或主動承接：**A させてください。**

> まず、前提条件を確認させてください。

全假名：まず、ぜんていじょうけんを かくにんさせて ください。

餐敘或會議中的簡短允許：

> こちらに座ってもよろしいですか。

全假名：こちらに すわっても よろしいですか。

## 句型 14：已確認、未確認、目前不支援

上台時只用下列三格，不創造第四種模糊答案。

### 已確認

> はい、現行版で対応しています。

全假名：はい、げんこうばんで たいおうしています。

### 需要逐案確認

> 構成によります。対象を確認させてください。

全假名：こうせいに よります。たいしょうを かくにんさせて ください。

### 目前不支援或未核准

> 現時点では、対応していません。

全假名：げんじてんでは、たいおうしていません。

> 正確な情報が手元にありません。確認してから回答します。

全假名：せいかくな じょうほうが てもとに ありません。かくにんしてから かいとうします。

「今後の検討項目です」只表示未來檢討，不表示承諾日期：

> イーサネット対応は、今後の検討項目です。

全假名：イーサネットたいおうは、こんごの けんとうこうもくです。

## 句型 15：問問題與確認理解

是非題：句尾加 **か**。

> 現在、シリアル通信をお使いですか。

全假名：げんざい、シリアルつうしんを おつかいですか。

開放題可用 **何／どの／いつ／どなた／どのように**。

> どのような用途を想定されていますか。

全假名：どのような ようとを そうていされていますか。

複述確認：**A という理解でよろしいでしょうか。**

> 量産前の検証時間が課題だという理解でよろしいでしょうか。

全假名：りょうさんまえの けんしょうじかんが かだいだという りかいで よろしいでしょうか。

聽不懂時不要猜：

> すみません、最後の部分をもう一度お願いできますか。

全假名：すみません、さいごの ぶぶんを もういちど おねがいできますか。

## 只需辨認的動詞變化

你不必一次學完變化；先認得下表，台上以右欄的固定說法為主。

| 功能 | 基本例 | 台上固定說法 | 全假名 |
|---|---|---|---|
| 現在／習慣 | 確認する | 確認します | かくにんします |
| 正在／狀態 | 対応する | 対応しています | たいおうしています |
| 否定 | 対応する | 対応していません | たいおうしていません |
| 過去 | 確認する | 確認しました | かくにんしました |
| 能力 | 確認する | 確認できます | かくにんできます |
| 必要 | 確認する | 確認する必要があります | かくにんする ひつようが あります |
| 請求 | 確認する | 確認していただけますか | かくにんして いただけますか |
| 先後 | 確認する | 確認してから回答します | かくにんしてから かいとうします |

## 主管問答的六格回答法

問題再難，也先用六格中的一格，不臨時發明答案。

1. **已確認**：はい、現行版で対応しています。  
   全假名：はい、げんこうばんで たいおうしています。
2. **有條件**：構成によります。対象を確認させてください。  
   全假名：こうせいに よります。たいしょうを かくにんさせて ください。
3. **目前不支援**：現時点では、対応していません。  
   全假名：げんじてんでは、たいおうしていません。
4. **資料不足**：正確な情報が手元にありません。確認して回答します。  
   全假名：せいかくな じょうほうが てもとに ありません。かくにんして かいとうします。
5. **範圍確認**：ご質問は、技術面についてでしょうか、それとも商務条件についてでしょうか。  
   全假名：ごしつもんは、ぎじゅつめんに ついてでしょうか、それとも しょうむじょうけんに ついてでしょうか。
6. **下一步**：対象機器と成功条件を確認し、次のステップをご提案します。  
   全假名：たいしょうききと せいこうじょうけんを かくにんし、つぎの ステップを ごていあんします。

## 十分鐘代換練習

每天從每欄各選一項，說出五句。只換一個槽位，保持其餘不變。

| A：主題 | B：動作 | C：條件／工具 |
|---|---|---|
| 画面設計（がめんせっけい） | ご説明します（ごせつめいします） | この画面で（この がめんで） |
| 通信設定（つうしんせってい） | 確認します（かくにんします） | エミュレーターで |
| 対応範囲（たいおうはんい） | 整理します（せいりします） | 対象ボードごとに（たいしょうボードごとに） |
| 商務条件（しょうむじょうけん） | 回答します（かいとうします） | 社内確認後に（しゃないかくにんごに） |

通關標準：看繁中提示後，三秒內說出一句；連續五句沒有把「現在、條件、未來」混在一起。通過後再回到 [15_84_DAY_TRAINING_PLAN.md](../japanese/15_84_DAY_TRAINING_PLAN.md) 的情境演練。
