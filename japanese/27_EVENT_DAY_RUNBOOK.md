# 日文產品介紹活動日 Runbook

## 目的

這份清單把正式活動拆成可執行步驟：簡報、Demo、高階問答、餐敘與會後追蹤。它不能取代通過 Gate；若尚未通過 Q&A Gate，應事先安排日語熟練同事或口譯支援，不要把客戶會議當第一次壓力測試。

## D-7：七天前

### 產品與商務事實

- [ ] 重新核對 **00_PRODUCT_TRUTH.md** 與目前 release build。
- [ ] 所有投影片主張都有 source ID。
- [ ] current、roadmap、待確認、不可對外四類已分開。
- [ ] 價格、授權、上市日期、SLA、試用、獨家與客製時程都有核准 owner。
- [ ] 若沒有核准答案，已寫好日文安全回答與可做到的回覆日期。
- [ ] 確認不再使用過期截圖、過期名稱或舊數字。

### 對象

- [ ] 對方公司、部門、姓名、職稱與姓名讀法。
- [ ] 誰是 GM、VP、技術決策者、商務決策者與通路負責人。
- [ ] 對方最可能關心的三個價值問題與三個風險問題。
- [ ] 這場會議真正要取得的下一步：試點、技術確認、商務會議或內部 sponsor。

### 角色分工

- [ ] 主講人。
- [ ] Demo 操作人。
- [ ] 技術深答 owner。
- [ ] 商務條件 owner。
- [ ] 日語救援或口譯。
- [ ] 記錄 owner、item、date 的人。

交棒句：

> 正確にお答えするため、技術担当から補足いたします。

全假名：せいかくに おこたえするため、ぎじゅつたんとうから ほそくいたします。

停頓：せいかくに おこたえするため / ぎじゅつたんとうから / ほそくいたします。//

這不是失敗，而是避免錯誤資訊。

## D-3：三天前

- [ ] 完成一次 5 分鐘 pitch＋7 分鐘 Demo＋20 分鐘 Q&A。
- [ ] 由陪練者隨機打斷至少兩次。
- [ ] 至少一次使用備援 Demo。
- [ ] 問答題序與平常不同，且包含一題完全未知問題。
- [ ] 依 **scorecard.csv** 評分，critical error 為 no。
- [ ] 只修三個最高風險項目，不重寫整份講稿。

若 D-3 仍有下列情況，立即縮短範圍：

- 30 秒開場無法穩定完成。
- Demo 時動作與旁白互相阻塞。
- 未知問題會靠猜。
- 產品名、重要版本或數字常被聽錯。

縮短為：30 秒定位＋三個價值點＋準備好的 Demo 結果＋由專人接手 Q&A。

## 活動日時間線

### T-90 分鐘

- 到場、確認動線與座位。
- 開機後不要更新系統或套件。
- 關閉通知、郵件彈窗與私人通訊軟體。
- 測試簡報、Demo、備援、聲音與麥克風。
- 把產品事實表、Q&A 速查與 owner 清單放在可立即開啟的位置。

### T-30 分鐘

- 與團隊確認誰回答技術、商務與通路問題。
- 說一次產品名、對方姓名與職稱。
- 喝水；不再完整彩排。
- 做三分鐘 mora 熱身：長音、促音、產品縮寫。

### T-5 分鐘

- 雙腳站穩，吐氣比吸氣長。
- 只想第一句，不在腦中重跑整份稿。
- 計時器、簡報器、備援路徑就位。

## 簡報中

- 每張投影片先看觀眾，再說結論，最後才轉向畫面。
- 一張投影片只要求觀眾記住一件事。
- 數字、限制與版本前後停半拍。
- 卡住時看該段第一語塊；仍想不起來就跳到下一段。
- 不說「抱歉我日文很差」。需要修復時直接使用專業句。

忘詞後跳段：

全假名：つぎの ポイントに すすみます。

停頓：つぎの ポイントに / すすみます。//

停頓：げんいんは / ログを かくにんするまで / だんていできません。//

## Q&A 操作流程

每題依序做：

1. 停半拍，讓對方說完。
2. 抓主題、要求、條件、題數。
3. 不確定就確認或拆題。
4. 第一段先答結論。
5. 用一至兩個理由或證據。
6. 說明限制。
7. 指定下一步。

確認問題：

> ご質問は、導入期間について、という理解でよろしいでしょうか。

全假名：ごしつもんは、どうにゅうきかんについて、という りかいで よろしいでしょうか。

停頓：ごしつもんは / どうにゅうきかんについて / という りかいで / よろしいでしょうか。//

拆題：

> 二つに分けてお答えします。まず価格、次にサポートについてご説明します。

全假名：ふたつに わけて おこたえします。まず かかく、つぎに サポートについて ごせつめいします。

停頓：ふたつに わけて / おこたえします。/ まず かかく / つぎに サポートについて / ごせつめいします。//

未知答案：

> 現時点では、正確な情報が手元にございません。担当チームに確認し、○月○日までに回答いたします。

全假名：げんじてんでは、せいかくな じょうほうが てもとに ございません。たんとうチームに かくにんし、○がつ ○にちまでに かいとういたします。

停頓：げんじてんでは / せいかくな じょうほうが / てもとに ございません。/ たんとうチームに かくにんし / ○がつ ○にちまでに / かいとういたします。//

回答後接回：

> では、先ほどのポイントに戻ります。

全假名：では、さきほどの ポイントに もどります。

停頓：では / さきほどの ポイントに / もどります。//

## 問答紅線

當場不得自行核准：

- 價格、折扣、margin、免費項目。
- 授權、NFR、試用、SLA。
- 區域獨家、account ownership、deal registration。
- 上市日期、roadmap 日期與未驗證技術能力。
- 客製範圍、費用、NRE、交期與維護責任。

若對方要求立即答應：

> ご要望は理解しました。ただし、この場で確約はできません。必要な条件を整理し、社内で確認します。

全假名：ごようぼうは りかいしました。ただし、このばで かくやくは できません。ひつような じょうけんを せいりし、しゃないで かくにんします。

停頓：ごようぼうは / りかいしました。/ ただし / このばで かくやくは できません。/ ひつような じょうけんを せいりし / しゃないで かくにんします。//

## 餐敘前

- [ ] 是否有過敏、宗教或飲食限制需要提前說明。
- [ ] 準備旅行、美食、城市、興趣、產業近況各一個問題。
- [ ] 準備三個 30 秒個人故事，不含機密客戶與內部爭議。
- [ ] 決定自己的飲酒界線；不要到現場才被迫想說法。
- [ ] 商務條件仍由正式 owner 核准，餐桌上不例外。

婉拒酒類：

> お酒はあまり強くないので、今日はノンアルコールでお願いします。

全假名：おさけは あまり つよくないので、きょうは ノンアルコールで おねがいします。

停頓：おさけは / あまり つよくないので / きょうは ノンアルコールで / おねがいします。//

自然追問：

> そうなんですね。特にどの点が印象に残りましたか。

全假名：そうなんですね。とくに どのてんが いんしょうに のこりましたか。

停頓：そうなんですね。/ とくに / どのてんが / いんしょうに のこりましたか。//

相槌只表示在聽。遇到商務要求時，不要只說「はい、わかりました」，應明確說需要確認。

## 當日或隔日跟進

- 感謝對方時間。
- 用三點內摘要已同意事項。
- 明確分開「已回答」與「仍在確認」。
- 每個待確認項目有 owner 與日期。
- 附上的簡報、影片與規格必須是可對外版本。
- 發送前由技術或商務 owner 核准高風險內容。

## 最後一分鐘口袋卡

只看這六個繁中意圖，不放全文：  
**問候 → 一句定位 → 三個價值點 → 請重說／確認 → 未知＋owner＋date → 三點收尾**

活動前能從這六個意圖自行說出日文，比拿著滿頁逐字稿更能應付打斷。
