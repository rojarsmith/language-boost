# 日文零基礎救命包

這一章不是文法課。目標是讓只記得五十音的人，今天就能完成問候、開始簡報、請對方重說、回答一個問題，以及在不知道答案時安全收尾。

## 先認識教材格式

每個句型有三行：

1. **自然日文**：正式場合真正要說的版本。
2. **全假名**：不要求你先會漢字。
3. **停頓行**：`/` 停半拍，`//` 停一拍；一口氣只說一個意群。

不要背羅馬字，也不要先分析每個助詞。先理解「這句要完成什麼工作」，再把整個語塊練成一個動作。

## 七條生存規則

1. 一句只放一個重點。
2. 先用短句答，再補理由。
3. 沒聽懂就確認，不要靠猜。
4. 不知道就說要確認，不能發明產品答案。
5. `はい` 可以只表示「我在聽」，但商務條件一定要明說是否同意。
6. 對客戶先穩定使用 `です／ます`；不必堆疊艱深敬語。
7. 卡住時跳到下一個訊息點，不要從第一句重來。

## A. 見面與自我介紹

### 1. 感謝對方撥時間

> 本日はお時間をいただき、ありがとうございます。

全假名：ほんじつは おじかんを いただき、ありがとうございます。

停頓：ほんじつは / おじかんを いただき / ありがとうございます。//

用途：正式會議、展會約談、餐敘都能使用。

### 2. 報上姓名與職責

> EDT HMI Studioを担当しております、王と申します。

全假名：イーディーティー・エイチエムアイ・スタジオを たんとうしております、おうと もうします。

停頓：イーディーティー・エイチエムアイ・スタジオを / たんとうしております。/ おうと もうします。//

把 `王` 換成自己的姓名。若日方已知道你的職務，也可縮短為：

> 王と申します。どうぞよろしくお願いいたします。

全假名：おうと もうします。どうぞ よろしく おねがいいたします。

停頓：おうと もうします。/ どうぞ よろしく おねがいいたします。//

### 3. 說明今天的順序

> 本日は、製品の概要、主な価値、実際の操作の順にご説明します。

全假名：ほんじつは、せいひんの がいよう、おもな かち、じっさいの そうさの じゅんに ごせつめいします。

停頓：ほんじつは / せいひんの がいよう / おもな かち / じっさいの そうさの じゅんに / ごせつめいします。//

### 4. 請對方隨時提問

> ご不明な点がございましたら、いつでもお知らせください。

全假名：ごふめいな てんが ございましたら、いつでも おしらせください。

停頓：ごふめいな てんが ございましたら / いつでも おしらせください。//

## B. 沒聽懂時

### 5. 請再說一次並放慢

> 申し訳ありません。もう一度、少しゆっくりお願いできますか。

全假名：もうしわけ ありません。もういちど、すこし ゆっくり おねがいできますか。

停頓：もうしわけ ありません。/ もういちど / すこし ゆっくり / おねがいできますか。//

### 6. 只重說最後一段

> 恐れ入りますが、最後の部分をもう一度お願いできますか。

全假名：おそれいりますが、さいごの ぶぶんを もういちど おねがいできますか。

停頓：おそれいりますが / さいごの ぶぶんを / もういちど おねがいできますか。//

### 7. 確認關鍵詞

> 「導入期間」という意味でよろしいでしょうか。

全假名：「どうにゅうきかん」という いみで よろしいでしょうか。

停頓：「どうにゅうきかん」という いみで / よろしいでしょうか。//

把 `導入期間` 換成 `価格`、`サポート範囲`、`対応ハードウェア` 等關鍵詞。

### 8. 用自己的話確認整題

> 導入期間についてのご質問、という理解でよろしいでしょうか。

全假名：どうにゅうきかんについての ごしつもん、という りかいで よろしいでしょうか。

停頓：どうにゅうきかんについての ごしつもん / という りかいで / よろしいでしょうか。//

### 9. 拆開多段問題

> ご質問を二ついただいたと理解しております。まず、価格についてお答えします。

全假名：ごしつもんを ふたつ いただいたと りかいしております。まず、かかくについて おこたえします。

停頓：ふたつ ごしつもん いただいたと / りかいしております。/ まず / かかくについて おこたえします。//

若不確定第二題，可接：

> その後で、二つ目のご質問をもう一度確認させてください。

全假名：そのあとで、ふたつめの ごしつもんを もういちど かくにんさせてください。

停頓：そのあとで / ふたつめの ごしつもんを / もういちど かくにんさせてください。//

全假名：すこし かんがえる おじかんを いただけますか。

停頓：すこし / かんがえる おじかんを / いただけますか。//

### 11. 查看手邊資料

> 手元の資料を確認してもよろしいでしょうか。

全假名：てもとの しりょうを かくにんしても よろしいでしょうか。

停頓：てもとの しりょうを / かくにんしても / よろしいでしょうか。//

### 12. 先答結論

> まず結論を申し上げ、その後で詳しくご説明します。

全假名：まず けつろんを もうしあげ、そのあとで くわしく ごせつめいします。

停頓：まず けつろんを もうしあげ / そのあとで / くわしく ごせつめいします。//

## D. 短而穩的回答骨架

### 13. 先說結論

> 結論から申し上げますと、個別の確認が必要です。

全假名：けつろんから もうしあげますと、こべつの かくにんが ひつようです。

停頓：けつろんから もうしあげますと / こべつの かくにんが ひつようです。//

### 14. 列出兩個理由

> 理由は二点あります。

全假名：りゆうは にてん あります。

停頓：りゆうは / にてん あります。//

> 一つ目は開発時間です。二つ目は検証のしやすさです。

全假名：ひとつめは かいはつじかんです。ふたつめは けんしょうの しやすさです。

停頓：ひとつめは / かいはつじかんです。/ ふたつめは / けんしょうの しやすさです。//

這一句只是回答結構示範；正式使用時，內容必須與產品事實表一致。

### 15. 限定現在能說的範圍

> 現時点でお伝えできる範囲では、こちらが確認済みの内容です。

全假名：げんじてんで おつたえできる はんいでは、こちらが かくにんずみの ないようです。

停頓：げんじてんで / おつたえできる はんいでは / こちらが かくにんずみの ないようです。//

### 16. 區分現行功能與未來項目

> この点は、現行版で確認済みです。

全假名：このてんは、げんこうばんで かくにんずみです。

停頓：このてんは / げんこうばんで / かくにんずみです。//

> この項目は今後の検討対象で、現行版の機能ではありません。

全假名：このこうもくは こんごの けんとうたいしょうで、げんこうばんの きのうでは ありません。

停頓：このこうもくは / こんごの けんとうたいしょうで / げんこうばんの きのうでは ありません。//

## E. 不知道答案時

### 17. 不靠猜測回答

> 正確な情報が手元にないため、今ここで推測してお答えすることは控えます。

全假名：せいかくな じょうほうが てもとに ないため、いま ここで すいそくして おこたえすることは ひかえます。

停頓：せいかくな じょうほうが / てもとに ないため / いま ここで すいそくして おこたえすることは / ひかえます。//

### 18. 指定確認人與日期

> 担当チームに確認し、○月○日までに回答いたします。

全假名：たんとうチームに かくにんし、○がつ ○にちまでに かいとういたします。

停頓：たんとうチームに かくにんし / ○がつ ○にちまでに / かいとういたします。//

日期要換成真正做得到的日期。`○日` 的讀法需另查日期表，例如三日是 `みっか`，不是 `さんにち`。

### 19. 重述待確認清單

> 確認する項目は、価格体系とサポート範囲の二点です。

全假名：かくにんする こうもくは、かかくたいけいと サポートはんいの にてんです。

停頓：かくにんする こうもくは / かかくたいけいと / サポートはんいの / にてんです。//

### 20. 理解需求，但不當場承諾

> ご要望は理解しました。ただし、この場で確約はできません。社内で確認します。

全假名：ごようぼうは りかいしました。ただし、このばで かくやくは できません。しゃないで かくにんします。

停頓：ごようぼうは / りかいしました。/ ただし / このばで かくやくは できません。/ しゃないで かくにんします。//

價格、折扣、區域獨家、上市日、SLA、客製時程都優先使用這類說法。

## F. 簡報與 Demo 控場

### 21. 請看畫面

> では、こちらの画面をご覧ください。

全假名：では、こちらの がめんを ごらんください。

停頓：では / こちらの がめんを / ごらんください。//

### 22. 說明這個畫面證明什麼

> ここで確認していただきたい点は、設定と動作が一つの流れになっていることです。

全假名：ここで かくにんして いただきたい てんは、せっていと どうさが ひとつの ながれに なっていることです。

停頓：ここで / かくにんして いただきたい てんは / せっていと どうさが / ひとつの ながれに なっていることです。//

內容只是句型範例；正式稿必須換成該畫面真正能證明的產品事實。

### 23. 回答後接回主線

> ありがとうございます。では、先ほどのポイントに戻ります。

全假名：ありがとうございます。では、さきほどの ポイントに もどります。

停頓：ありがとうございます。/ では / さきほどの ポイントに / もどります。//

### 24. Demo 失敗時

> デモ環境で問題が発生しました。原因を推測せず、まずは準備した画面を使って説明を続けます。

全假名：デモかんきょうで もんだいが はっせいしました。げんいんを すいそくせず、まずは じゅんびした がめんを つかって せつめいを つづけます。

停頓：デモかんきょうで / もんだいが はっせいしました。/ げんいんを すいそくせず / まずは じゅんびした がめんを つかって / せつめいを つづけます。//

> 原因と対応状況を確認のうえ、明日午後三時までにご報告します。

全假名：げんいんと たいおうじょうきょうを かくにんのうえ、あした ごご さんじまでに ごほうこくします。

停頓：げんいんと たいおうじょうきょうを / かくにんのうえ / あした ごご さんじまでに / ごほうこくします。//

只有真正做得到時才說明確時間。

## G. 餐敘最低生存句

### 25. 感謝邀請

> 本日はお招きいただき、ありがとうございます。

全假名：ほんじつは おまねきいただき、ありがとうございます。

停頓：ほんじつは / おまねきいただき / ありがとうございます。//

若並非對方作東，改用第 1 句較安全。

### 26. 問來台經驗

> 台湾にはいらっしゃったことがありますか。

全假名：たいわんには いらっしゃったことが ありますか。

停頓：たいわんには / いらっしゃったことが / ありますか。//

### 27. 問住宿或行程感受

> 今回のご滞在はいかがですか。

全假名：こんかいの ごたいざいは いかがですか。

停頓：こんかいの ごたいざいは / いかがですか。//

### 28. 聽完再追問

> そうなんですね。特にどの点が印象に残りましたか。

全假名：そうなんですね。とくに どのてんが いんしょうに のこりましたか。

停頓：そうなんですね。/ とくに / どのてんが / いんしょうに のこりましたか。//

不要對上級使用不自然的 `なるほどですね`。`そうなんですね`、`勉強になります` 或直接重述對方重點更穩妥。

### 29. 婉拒酒類

> お酒はあまり強くないので、今日はノンアルコールでお願いします。

全假名：おさけは あまり つよくないので、きょうは ノンアルコールで おねがいします。

停頓：おさけは / あまり つよくないので / きょうは ノンアルコールで / おねがいします。//

### 30. 說明食物過敏

> 申し訳ありません。えびにアレルギーがあります。

全假名：もうしわけ ありません。えびに アレルギーが あります。

停頓：もうしわけ ありません。/ えびに / アレルギーが あります。//

把 `えび` 換成實際過敏食材；過敏屬安全事項，不要含糊使用 `大丈夫です`。

### 31. 餐敘收尾

> 本日はご一緒できて、とても楽しかったです。ありがとうございました。

全假名：ほんじつは ごいっしょできて、とても たのしかったです。ありがとうございました。

停頓：ほんじつは / ごいっしょできて / とても たのしかったです。/ ありがとうございました。//

## 容易造成風險的說法

| 不建議直接說 | 問題 | 改用 |
|---|---|---|
| わかりません。 | 太突然，也沒有下一步 | 現時点では正確な情報が手元にありません。確認して回答します。 |
| たぶんできます。 | 容易被當作產品承諾 | 対応可否を確認します。 |
| 絶対に問題ありません。 | 無法證明的絕對保證 | 現在確認できている範囲では、問題はありません。 |
| 大丈夫です。 | 可能表示可以、不需要或沒問題 | 接受、拒絕與確認內容都明確說出來 |
| はい、わかりました。 | 在談判中可能被聽成同意條件 | ご要望は理解しました。条件は社内確認が必要です。 |
| なるほどですね。 | 對高階對象不夠穩妥，且常顯得口語不自然 | そうなんですね。／おっしゃる点は理解しました。 |

## Day 1：二十分鐘直接開始

1. 3 分鐘：拍手念 `本日は／お時間をいただき／ありがとうございます`，每個假名一拍。
2. 5 分鐘：第 1、2、5 句各 echo 三次。
3. 4 分鐘：第 7、10、17、18 句各說兩次。
4. 3 分鐘：不看日文，只看「問候、重說、確認、未知＋日期」四個中文意圖回想。
5. 3 分鐘：請語音教練問一題你聽不懂的產品問題；先請它放慢，再確認關鍵詞。
6. 2 分鐘：完整錄一次，不重來，結果填入 `practice_log.csv`。

今天只要求完成，不要求好聽。

## 生存 Gate

從下列十個意圖隨機抽八個：問候、自介、說明順序、請重說、確認關鍵詞、拆題、爭取時間、先答結論、未知＋日期、回答後接回。八個都能在五秒內開始，且沒有虛構資訊，才算單次達標。

必須在三個不連續日期達標才算真正通過；同一天連續背對三次，只代表短期記憶。
