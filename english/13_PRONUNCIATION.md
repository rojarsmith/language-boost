# 發音、重音、停頓與台灣人常見錯誤

## 先接受一件事

你不需要消除台灣口音。你需要讓關鍵字第一次就被聽懂。優先順序是：

1. 句子重音。
2. 關鍵字尾音。
3. 合理停頓。
4. 說慢一點。
5. 最後才是單一音標的完美度。

## 技術縮寫一律拆開念

- LVGL：L–V–G–L
- CJK：C–J–K
- GUI：可念 `goo-ee`；緊張時拆成 G–U–I 也可以
- MCU：M–C–U
- SWD：S–W–D
- QSPI：Q–S–P–I
- STM32：S–T–M thirty-two

## 句子重音

英文不是每個字一樣重。以下只重讀粗體：

> EDT HMI Studio brings **SCREEN DESIGN**, **DEVICE COMMUNICATION**, and **DEPLOYMENT** into **ONE PROJECT**.

小字 `brings`, `and`, `into` 輕輕帶過。這比每個音都標準更容易聽懂。

## 思意群與停頓

錯誤：一路念到底。

> Users can design screens connect values test the application and deploy to supported hardware.

正確：

> Users can design screens, / connect device values, / test the generated application, / and deploy to supported hardware. //

`/` 半拍，`//` 一拍。停頓時閉嘴，不要填 `uh`。

## 台灣人最值得修的四件事

### 1. 保留字尾

- code**d** / supporte**d** / buil**d** / tes**t** / projec**t**
- 不用誇張，只要讓氣流或舌位存在。

### 2. V 不要變 W

`value`, `visual`, `version`：上排牙齒輕碰下唇，再出聲。

### 3. 長句拆短

不要為了文法把五個資訊塞一個句子。每次呼吸講一件事。

### 4. 數字放慢

> eight hundred by four eighty  
> four eighty by two seventy-two  
> November twenty twenty-six  
> nine thousand six hundred baud

## 每日五分鐘口腔熱身

每句三次，先慢再正常：

1. > We **BUILD** the screen.
2. > We **BIND** a value.
3. > We **TEST** the generated code.
4. > We de**PLOY** to supported hardware.
5. > The **CURRENT BUILD** supports Modbus R-T-U.
6. > I will **CONFIRM** the approved pricing.

## 語速

- 新手簡報：每分鐘 90–110 字。
- 熟練後：每分鐘 110–125 字。
- 問答：第一句比簡報再慢 10%。

錄音時不追求快。若聽起來像在背密碼，就再慢 15%。
