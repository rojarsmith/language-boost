# 上台一頁速查表

## 一句定位

> EDT HMI Studio is a visual, no-code, AI-assisted environment that helps teams create, connect, test, and deploy embedded touch interfaces from one project.

## AI 一句

> The assistant can create or edit normal project content through the editor. A person reviews the result and can undo the applied AI change as one step.

## 五步

> Design the screens.  
> Define the logic.  
> Connect device values.  
> Validate the generated application.  
> Deploy to supported hardware.

## 三個價值

> Fewer handoffs.  
> Earlier integration feedback.  
> A more repeatable path from evaluation to hardware.

## 最強證據

> The Emulator compiles the generated C with real LVGL and runs events, logic, and simulated device communication.

## 目前範圍

> Public 0.8.5 Alpha for key-stakeholder evaluation.  
> Three physical board profiles, plus Virtual Model.  
> Development build: 21 normal-palette widgets; 27 in Factory Mode.  
> Modbus RTU and configurable serial commands on implemented serial paths.  
> Multi-screen UI, animations, multilingual text, fonts, images, and board-aware deployment.
