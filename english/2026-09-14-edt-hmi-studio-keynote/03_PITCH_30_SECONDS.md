# 30 秒產品介紹：先練到不用想

## 極簡安全版

先只背這七句。正常語速約 30–40 秒；新手慢速約 45 秒。

> Good morning.  
> This is EDT HMI Studio.  
> It is a visual, no-code, AI-assisted environment for embedded touch interfaces.  
> The assistant can create or edit the interface.  
> Teams can connect device values and test the generated application.  
> Everything stays editable in one project, and supported targets can continue to deployment.  
> The goal is shorter development cycles and fewer integration problems.

中文意思：

> 早安。這是 EDT HMI Studio。它是一套用於嵌入式觸控介面的視覺化、無程式碼、AI 輔助開發環境。AI 助理可以建立或修改介面。團隊可以連接設備數值並測試產生的應用程式。所有內容都能在同一專案中繼續編輯，支援的 target 可以接著部署。目標是縮短開發週期並減少整合問題。

## 停頓與重音版

大寫字要加重，斜線停半拍：

> Good **MORN**ing. /  
> This is **E-D-T H-M-I STU**dio. /  
> It is a **VIS**ual, / **NO-CODE**, / AI-assisted environment / for em**BED**ded touch interfaces. /  
> The assistant can cre**ATE** / or **ED**it the interface. /  
> Teams can con**NECT** device values / and **TEST** the generated application. /  
> Everything stays **ED**itable / in **ONE PROJ**ect, / and supported targets can continue / to de**PLOY**ment. /  
> The goal is **SHORT**er development cycles / and **FEW**er integration problems.

## 一句一句練

| 英文 | 中文 | 練習重點 |
|---|---|---|
| Good morning. | 早安。 | 微笑；不要把 `morning` 尾音吃掉。 |
| This is EDT HMI Studio. | 這是 EDT HMI Studio。 | EDT、HMI 都逐字母念。 |
| It is a no-code development environment. | 它是無程式碼開發環境。 | 先練短版，再加後半句。 |
| It is for embedded touch interfaces. | 它用於嵌入式觸控介面。 | `embedded` 重音在 BED。 |
| The assistant can create or edit the interface. | AI 助理可以建立或修改介面。 | `assistant` 與 `interface` 要說清楚。 |
| Users can design screens. | 使用者可以設計畫面。 | `design` 的 s 發 /z/。 |
| Users can connect device values. | 使用者可以連接設備數值。 | `connect` 重音在 NECT。 |
| Users can test the generated application. | 使用者可以測試產生的應用程式。 | 不必念很快。 |
| Users can deploy to supported hardware. | 使用者可以部署到支援的硬體。 | 一定要保留 `supported`。 |
| Everything stays in one project. | 全部留在同一專案。 | 最容易懂的核心價值。 |
| The goal is shorter development cycles. | 目標是縮短開發週期。 | 不是宣稱已量化縮短多少。 |

## 對高階主管的 35 秒版

> EDT HMI Studio brings embedded HMI development into one AI-assisted visual workflow. The assistant can create or edit the interface, while the team connects behavior and device values, runs the generated application in an Emulator, and continues to supported hardware. This is designed to reduce handoffs and find integration problems earlier.

## 對通路商的 35 秒版

> EDT HMI Studio helps customers move from a display idea to a running embedded interface in one workflow. It combines screen design, visual logic, device communication, emulation, and deployment. For a distributor, that means a clearer demo, faster technical evaluation, and a more repeatable way to support customer projects.

## 背稿方法

不要一次背整段。用七張腦內卡片：

1. Product — EDT HMI Studio
2. What — visual, no-code, AI-assisted
3. AI — create or edit
4. Connect and test — device values + Emulator
5. Project — everything stays editable
6. Deploy — supported targets
7. Value — shorter cycles + fewer problems

忘記一句就跳到下一張卡，不要停下來回想原文。

## 過關標準

- 不看稿完成。
- 45 秒內完成。
- 沒有一次停頓超過兩秒。
- `AI-assisted`, `embedded`, `interface`, `generated`, `deploy`, `supported` 都說清楚。
- 沒有把 `supported hardware` 說成 `any hardware`。
