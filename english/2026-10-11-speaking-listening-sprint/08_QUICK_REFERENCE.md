# 面試與會議句型速查

練習前挑五句，關掉文字用中文提示說英文。速查表用於複習；實際面試是否能使用筆記，依對方規則。

## 聽不懂與確認

| 英文 | 中文 |
| --- | --- |
| Could you say that again, please? | 請再說一次 |
| Could you speak a little more slowly? | 請稍慢一點 |
| Could you repeat the last part? | 請重說最後一段 |
| What do you mean by “[word]”? | 這個字指什麼？ |
| Let me make sure I understand. | 我確認一下是否理解 |
| Do you mean [A] or [B]? | 你指 A 還是 B？ |
| Are we allowed to [action]? | 可以做這件事嗎？ |
| Is that the minimum or the maximum? | 是最低還是最高？ |

## 自介與真實故事

| 英文 | 中文 |
| --- | --- |
| I work on [area]. | 我做哪個領域 |
| I was responsible for [my part]. | 我當時負責哪部分 |
| The main problem was [problem]. | 主要問題 |
| Our goal was [goal]. | 我們的目標 |
| First, I [action]. Then, I [action]. | 先做什麼，再做什麼；故事中填過去式 |
| I chose [option] because [reason]. | 我選某方案的理由 |
| As a result, [true outcome]. | 真實結果 |
| Next time, I would [change]. | 下次我會改什麼 |

三個故事提示詞：**問題／行動／結果**。被追問時補理由、證據或下次改法，不必從頭講整個故事。

## 工程師解題

| 英文 | 中文 |
| --- | --- |
| Let me confirm the requirements. | 我確認需求 |
| Can the input be empty? | 輸入可空嗎？ |
| Can I change the input? | 可以改輸入嗎？ |
| I will start with a simple solution. | 先從簡單解法開始 |
| This uses [time] and [space], under [assumption]. | 在某假設下的時間與空間成本 |
| Let me test an edge case. | 測一個邊界情況 |
| That changes the requirements. | 那改變了需求 |
| I found a problem in this step. | 這一步有問題 |

## 工程經理決策

| 英文 | 中文 |
| --- | --- |
| I need to understand the impact first. | 先了解影響 |
| What is the most important outcome? | 最重要的成果是什麼？ |
| We need to agree on the priority. | 需要確認優先順序 |
| I would compare the risks and options. | 我會比較風險與選項 |
| I would explain the trade-off. | 我會說明取捨 |
| We agreed on [owner], [action], and [date]. | 確認負責人、行動、日期 |
| I gave feedback on [specific behavior]. | 對具體行為給回饋 |
| My role in the decision was [true role]. | 我在決策中的真實角色 |

## 生活與商務

| 英文 | 中文 |
| --- | --- |
| I'd like [item], please. | 我想要… |
| How much is it? | 多少錢？ |
| Could you show me on the map? | 可以指在地圖上嗎？ |
| I have a reservation under [name]. | 訂位姓名是… |
| My current estimate is [date]. | 目前估計是某日 |
| I need to confirm the scope first. | 需要先確認範圍 |
| Does the price include [item]? | 價格含某項目嗎？ |
| Could you confirm the date and time zone? | 可以確認日期與時區嗎？ |
| I will update you by [time]. | 我會最晚何時更新 |
| Let me summarize the next steps. | 我總結下一步 |

## 不確定時用這三句

> I don't know the exact number. I can explain how we measured it.
>
> 我不知道精確數字，但可以解釋衡量方法。

> I haven't worked with that directly. Here is how I would learn more about it.
>
> 我沒有直接做過，以下是我會如何進一步了解。

> I need a moment to think. May I explain my first idea?
>
> 我需要想一下，可以先解釋第一個想法嗎？

## 最後一分鐘確認

我是否回答了問題？我是否說明本人做了什麼？數字、否定、時間是否有確認？對方是否知道下一步？這四項比塞進更多難字更值得先檢查。
