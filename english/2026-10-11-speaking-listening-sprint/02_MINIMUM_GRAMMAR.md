# 聽說先用的最小文法

這七天先學能表達「人物、行動、時間、原因、條件」的句型。每次只選三至五句，換自己的內容並出聲說。英文短句只要資訊準確、對方聽得懂，就能繼續對話；文法修正則從會改變意思的錯誤開始。

## 句子的基本順序

**誰 → 做什麼 → 對象 → 時間或條件。**

> I / fixed / the bug / yesterday.
>
> 我／修復了／這個錯誤／昨天。

I 是我，we 是我們，the team 是團隊。不要把團隊成果全部說成 I；也不要用 we 遮住自己的貢獻。

> The team built the service. I designed the API.
>
> 團隊建立了服務。我設計了 API。

## 八組先會用的句型

| 用途 | 句型與例子 | 中文 |
| --- | --- | --- |
| 身分與狀態 | I am a software engineer. / The service is slow. | 我是軟體工程師／服務很慢 |
| 現在的工作 | I work on APIs. / Our team builds software. | 我負責 API／團隊開發軟體 |
| 過去做的事 | I fixed the bug. / We changed the plan. | 我修好了錯誤／我們改了計畫 |
| 正在進行 | I am testing the change. | 我正在測試這項變更 |
| 下一步 | I will check the logs. | 我會檢查紀錄 |
| 能力與請求 | I can explain the design. / Could you repeat the question? | 我能解釋設計／請重說問題 |
| 原因與結果 | We used a cache because the database was slow. / The database was slow, so we added a cache. | 因資料庫慢而使用快取／資料庫慢，所以加了快取 |
| 條件 | If the input is empty, I will return an empty list. | 若輸入空白，我會回傳空清單 |

is / am / are 用於身分、狀態，以及 is doing 這類進行式。一般動作不用多加一個 am：**I work**，不是 I am work。he / she / it 或單數名詞現在式常加 s，例如 The service works。

## 現在過去未來別混在一起

| 時間 | 例子 | 一眼提示 |
| --- | --- | --- |
| 現在常態 | I manage the project. | 通常做的事情 |
| 過去 | I managed the project last year. | 已發生的事情 |
| 下一步 | I will manage the next release. | will 後接原形 |

常用過去式：work → worked、fix → fixed、use → used、test → tested、build → built、make → made、choose → chose、lead → led、do → did、have → had、go → went。

**過去否定／問句用 did 後，動詞回原形：**

> I did not change the database. 我沒有改資料庫。
>
> Did you test the change? 你測試了這項變更嗎？

不是 I didn't changed 或 Did you tested。描述結果時先練 **We reduced the response time.**；現在完成式如 **I have worked with Java for five years.** 可以之後再補，不必第一天重學所有時態。

## 聽懂問句是在要哪種資訊

| 問句 | 要回答什麼 | 起手句 |
| --- | --- | --- |
| What did you do? | 你的行動 | I checked the logs. |
| Why did you choose it? | 原因 | I chose it because… |
| How did you solve it? | 方法或步驟 | First, I… Then, I… |
| Who was responsible? | 負責人 | I was responsible for… |
| When will it be ready? | 時間 | It will be ready by… |
| How many users? | 數量 | About… users. |
| How much does it cost? | 金額 | It costs… dollars. |
| What if it fails? | 失敗時的處理 | If it fails, I will… |

同一意思有不同問法：**What did you do? / What was your role? / What were you responsible for?** 都可能在問你的貢獻。先抓意思，不要依某一個固定開頭才會答。

## 否定比較數量會改變題意

- **can / cannot**：能／不能。聽不清楚時問：**Is that allowed?**，不要猜。
- **must / must not**：必須／不得。
- **more / less / fewer**：更多／更少；數量比較例句 **fewer requests**。
- **at least / at most**：至少／至多。
- **before / after / by**：在之前／之後／最晚到某時。
- **only / except**：只有／除了。

> We can change the API. / We cannot change the API.
>
> 可以／不可以改 API。

> The budget is at most five thousand dollars.
>
> 預算至多五千美元。

聽到時間要確認日期與時區：**Do you mean Friday, October 16, at 9 a.m. Pacific Time?** 這是句型示例，實際對話請使用對方提供的日期、時間與時區，不要自行換算猜測。

## 把長句拆成三句

初學者容易試著把中文長句一次翻完。先拆資訊：

> The service was slow. I checked the logs. I found a slow database query.
>
> 服務很慢。我檢查了紀錄。我找到一個很慢的資料庫查詢。

經理版本：

> We had two urgent projects. I talked with the product team. We agreed to deliver the smaller one first.
>
> 我們有兩個緊急專案。我和產品團隊討論。我們同意先交付較小的一個。

熟練後才接 because、so、but。先保留意思，不要在腦中同時處理文法名稱和整段翻譯。

## 五分鐘替換練習

用下面六句，填自己的事實。每句念三次，第二輪只看中文，第三輪不看稿。

1. I work on [什麼].
2. Last year, I built [什麼].
3. I chose [方案] because [理由].
4. The main problem was [問題].
5. If [條件], I will [行動].
6. Could you explain [不懂的部分]?

再請伙伴只念 What / Why / How 開頭的題目，你選適合的句型回答。不要把每題都答成背好的自介。

## 修正順序

先修會改變意思的否定、時間、數字及個人責任；再修句子缺動詞、問句聽錯；最後處理冠詞、介系詞或較自然的說法。每回合修兩項，修完重說一次完整答案。
