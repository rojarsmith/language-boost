## 重跑

```powershell
npm run dev
```

另開終端，在已有 Playwright／Chromium 的環境：

```powershell
node tests/poc.cjs
```

若套件與瀏覽器在其他位置，可設定 `PLAYWRIGHT_PACKAGE` 與 `PLAYWRIGHT_EXECUTABLE`。`POC_URL` 預設為 `http://localhost:8000`；測試會寫入全新的測試瀏覽器 localStorage，輸出截圖到忽略的 `.tmp/poc-qa/`。

## 部署後手動驗收

1. 在 Vercel 的 HTTPS 網址開啟英語與日語情境，確認對應語音能播放與停止。
2. 允許麥克風，錄製自己的短答、停止並回聽，確認關閉練習後錄音不再保留。
3. 若要使用語音辨識，先閱讀並勾選說明；核對實際辨識文字，勿視為發音評分。
4. 完成一次任務，重新整理同一網址，確認紀錄、偏好與複習時間保留。
5. 匯出 JSON，確認其中有回答、時間與偏好；在共用裝置離開前可清除本機紀錄。
6. 以真人音訊與真人陌生問法試練，檢查能否理解與澄清；這項效果沒有由自動化測試驗證。
